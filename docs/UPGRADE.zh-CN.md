# 升级已有主机与设备

[文档目录](README.md) · [当前测试版说明](releases/v0.1.0-test.9.zh-CN.md) · [Mac App 使用](APP_DESKTOP.zh-CN.md) · [完整安装与受控刷写](INSTALLATION.zh-CN.md) · [实验性固件回退流程](FIRMWARE_UPDATE_ROLLBACK.zh-CN.md)

先读**目标版本 Release 说明**，确认它究竟是后端更新、固件更新还是两者都有。`v0.1.0-test.9` 更新 App 入口、菜单栏与安全生命周期，也包含新闻状态和黄金统一计算的后端/固件源码。**不含固件二进制，不要求为了主机更新刷屏**；旧固件不能完整展示新期刊状态和黄金基准标签，不能将仅更新 App 说成整套硬件修复已完成。此前测试版附件保持不变。切换前停用旧发布者及其自动重启；独立目录的文件锁不会阻止两个实例写同一云端设备。迁移与回退都保存最新调用预算、出刊去重、金价基准和请求状态，不能直接拿迁移前快照覆盖新状态。

## 已有 App 升级到 test.9

1. 先核对无在途固件/付费任务，从 Is →“退出 InkSight”（旧版按原退出方式）安全结束，确认后台和旧发布者已停止；不要强杀正在写入的进程。
2. 在私有位置备份旧 App、`~/Library/Application Support/InkSight-GLHF/` 与系统偏好。校验新 App ZIP 后，在**原安装路径**替换应用，保留旧 App 副本，不移动或删除用户数据目录。
3. 打开新版，受管数据会迁移到新版本目录，旧目录保留。逐项检查配置、账本、去重、登录启动状态及唯一发布者。Is →“打开配置”现在无需 root，旧账户记录不删除；关闭窗口改为后台驻留，退出须走 Is 菜单。
4. 图标旁应显示当前有效 Codex 7D 剩余百分比，缺失或过期为 `-`。再核对云端时间和实体屏；云端回读不是设备收件证明。黄金新版实体屏仍是待验证项。

## 改用独立 Mac App

App 会在当前用户的 `Application Support/InkSight-GLHF/` 下建立自己的私有版本目录，**不会自动读取或修改现有源码部署**。先在私有位置完整备份旧源码目录的配置、数据库和状态。停旧后端与发布循环，再打开 App；需要迁移时使用 App 的“选择性导入旧源码数据”预览、备份、确认流程，随后逐项核对本机管理页、采集状态与云端发布。不要同时运行两个发布端来操作同一设备。若已有 App 旧版，新版会保留旧版本目录并复制受管私有数据；升级前仍须自行备份。回退时先停新 App，保留运行后最新数据，再按兼容范围受控恢复旧程序与状态；本版没有一键回退按钮。详见[Mac App 使用说明](APP_DESKTOP.zh-CN.md)。

## 开始前

1. 停止前台后端与发布器，记录当前使用的源码版本、设备固件目标与配置 schema。不要把升级和日常发布同时运行。
2. 在**本机私有位置**备份当前源码、`shared/config/` 内真实配置、`shared/backend/` 下的数据库与 `state/`、本机 `.env`，并核对备份能读；不要提交、上传 Issue 或分享。升级版本如另有迁移说明，以该版本为准。
3. 下载[目标版本的源码和同版校验文件](DOWNLOAD.zh-CN.md)，检查 SHA-256。不要把 GitHub 自动生成源码 ZIP 当作已验收的发行资产。

## 仅更新源码后端（test.2 用户可继续走这条）

把新源码放在**新的独立目录**，先按[首次使用](FIRST_USE.zh-CN.md)安装该版本的锁定依赖。不要对生产目录运行空白 `init` 或把新示例文件覆盖自己的私密配置；将备份的配置与状态按对应版本说明受控迁移，再执行 `shared/tools/inksight_config.py validate`。若仍使用旧 `manual_settings.json`，先执行 `migrate --dry-run`，审阅后才决定是否 `--apply --confirm-activate`。更换源码与状态的一致性由部署者核对，切勿把新状态随意交给旧版代码读取。

确认无误后用新版本 `shared/backend/run-backend.sh` 前台启动，检查本机 `http://127.0.0.1:8080/api/health`、管理端及实际需要的数据时间戳。单一健康返回不证明报价或设备发布新鲜；若使用坚果云，再按[主机发布指南](HOST_RUNTIME.zh-CN.md)做一次发布/回读核验。主机需保持唤醒，睡眠期间不保证出刊。

## 只有目标版本明确要求时才刷写固件

当前测试版没有可下载的固件 `.bin`。要自行构建，先按[完整安装指南](INSTALLATION.zh-CN.md)合法取得/导入 MiSans，显式指定 `epd_426_ssd1677_s3_n32r16`；不要直接用 `platformio.ini` 中的历史默认环境。管理端受控流程区分真正空白板的 `fresh` 与已有设备的 `update`：后者要求分区表匹配、先备份 NVS/OTA/应用区、写未运行分区并校验。不要对未知设备猜串口、全盘擦除或绕开拒绝条件。Wi-Fi 列表是下次构建的完整快照，省略的旧网络可能在新固件首次启动时从 NVS 删除。

## 回退

先停止新后端/发布器，私密保存运行后最新账本、预算、出刊及请求去重记录。旧版 [test.5](https://github.com/NuoYe-CCnC/InkSight-GLHF/releases/tag/v0.1.0-test.5)程序仍可下载，但不可直接倒灌升级前快照造成重复付费；先核对状态兼容性，必要时请维护者协助受控迁移，再启动唯一旧发布者。不能只降代码而让旧版解释新版状态。设备若实际刷写过，按对应受控备份和回退说明处理；本次未提供固件，不声称有已验收的设备端一键回退。回退失败请保留私有备份和日志，按[故障排查](TROUBLESHOOTING.zh-CN.md)定位，不要公开凭据。

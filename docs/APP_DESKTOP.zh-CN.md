# InkSight Mac 应用：安装与首次使用

[下载文件](DOWNLOAD.zh-CN.md) · [升级和回退](UPGRADE.zh-CN.md) · [源码安装](FIRST_USE.zh-CN.md)

`v0.1.0-test.3` 提供独立的 `InkSight.app` 测试包。已在 **Apple Silicon、macOS 26.5.2** 上用中文和空格路径、只读应用目录、全新用户数据目录测试。App 内含 Python 3.11.15 和锁定依赖；运行时不要求另外安装 Python、Homebrew 或克隆源码。其他 macOS 版本、Intel Mac、Windows 与 Linux 未完成同级验收。

这版只有**临时 ad-hoc 签名，没有 Apple Developer ID 签名或公证**。从网络下载后，macOS 可能阻止首次打开。请先核对下载来源和 SHA-256；若仍决定试用，仅按 [Apple 官方安全说明](https://support.apple.com/en-gb/102445)自行在“系统设置 → 隐私与安全性”处理提示。不要在终端全局关闭 Gatekeeper，也不要为本项目关闭系统安全功能。若需要无需安全例外的常规安装体验，应等待以后完成 Developer ID 签名和 Apple 公证的版本。

## 安装

1. 从 [本版本 Release](https://github.com/NuoYe-CCnC/InkSight-GLHF/releases/tag/v0.1.0-test.3)下载 `InkSight-macOS-arm64.zip` 和同名 `.sha256`。在下载目录运行 `shasum -a 256 -c InkSight-macOS-arm64.zip.sha256`，确认报告 `OK`。校验失败不要打开。
2. 解压 ZIP，把 `InkSight.app` 拖到“应用程序”文件夹。应用体积较大，是因为 Python 与依赖均已包含。不要在 `.app` 内填写配置或保存数据。
3. 打开 InkSight。首次运行会在 `~/Library/Application Support/InkSight-GLHF/` 建立**当前用户独有**的配置、数据库与运行目录；应用目录保持只读。App 自动启动仅监听 `127.0.0.1` 的本机后端，并打开本机配置页。默认端口为 `18080`，可在 App 中改端口并重启。端口被占用时不会接管别的进程。
4. 浏览器提示创建第一位管理员时，自行设置用户名和至少 12 位密码。**没有统一默认账号或密码**。不要把密码、密钥或配置发到公开 Issue。

控制窗口分别显示“后端健康”“采集新鲜度”“云端发布”“设备连接”；后端健康只证明本机服务可用，不代表新闻或报价新鲜，也不代表实体屏已经收到数据。刚安装且未启动采集时，“尚无采集结果”正常。按“检查采集”只检查本机汇总文档，不会调用付费接口。

## 可选服务与实体设备

新的 App 默认**不开启后台网络采集**；未配置新闻密钥时仍使用本地寄语。先在本机管理页填写所需服务，再审查数据来源和潜在费用；仅在明确需要时打开“允许下次启动运行已配置的后台网络采集”并重启。开关只影响下次启动。不要把 API 密钥填到固件或公开仓库。

要发布到现有设备，先在管理页填写坚果云 WebDAV，再在 App 内输入设备 MAC，按“测试云端”。该操作经你主动点击后会做 WebDAV 上传、回读、清理测试，**不会调用付费模型**。测试成功后才可按“启动发布”。这只能证实云端链路；设备是否拉取并正确上屏，仍需实机确认。关闭 App、按“停止”或 Mac 休眠时不能保证继续发布；意外退出后由 App 启动的后端和发布循环会停止。固件烧录、接线和 MiSans 导入仍需遵循[完整安装指南](INSTALLATION.zh-CN.md)，这版不含可直接刷写的固件。

## 数据、旧版导入与升级

应用每个版本有独立目录：`~/Library/Application Support/InkSight-GLHF/versions/<版本>/source/`；`current.json` 标识当前版。私密配置、数据库、状态与本机令牌留在这个用户数据目录，**不进入应用包或 GitHub 发布资产**。升级到后续 App 版本时，安装器复制旧版受管数据到新版本目录并保留旧目录；切换前验证配置。升级前仍建议另做私密备份，切勿把备份公开。

已有源码部署**不会自动导入**。若需要迁移，先关闭其他源码服务、在 App 点“停止”，选“选择性导入旧源码数据”，核对预览并明确确认。原目录不修改；App 内当前数据先备份，导入失败不替换现有目录。导入后再启动并逐项检查。不要选正在运行的生产目录来反复试验；先复制到私有备份目录更稳妥。仅切换本机 App 不要求重刷设备，本版也未改变固件。

回退时先退出新 App、保留 `Application Support` 数据，再用旧版 App 和对应旧版数据目录恢复；不要让旧版程序直接解释更新后的状态。此测试版没有自动一键回退按钮。手动迁移与回退前，请保存同一时点的配置、数据库和状态备份。

## 本版限制

- 只验证本机隔离启动、首位管理员创建、服务和进程生命周期；未做第二台全新 Mac、长期睡眠恢复、真实坚果云账号或实体设备的本版端到端验收。
- App 与发布端必须在主机保持运行和联网时工作；Mac 休眠期间不能保证定时采集或出刊。
- 未完成 Apple 公证。`codesign` 校验通过不等于 Apple 已验证开发者身份，也不等于 Gatekeeper 会允许下载后的无提示启动。
- 如需开发、编译固件或检查实现，另下载同版 `InkSight-Source.zip`；该源码包不是安装器。

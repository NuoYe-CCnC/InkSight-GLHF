# 许可证、SBOM 与资源来源

## 项目来源

源码注释和现有文档指向 `datascale-ai/inksight`；其公开仓库顶层许可证是 MIT。2026-09-14 检查到的上游 HEAD 为 `ea73138e8f69b8632d39295afeab32c3560d92c4`；代表性内置模式 `daily.json` 和固件内机器人位图与该提交一致。候选保留上游 MIT 原文。但当前工作目录没有 `.git`，无法证明该 HEAD 就是实际分叉基准，也无法仅凭文件内容证明后来每项修改的作者和授权，所以顶层许可证不能自动替用户决定。

完整本机 Python 依赖闭包和版本在根目录 `SBOM.json`；精确版本快照在 `requirements.lock.txt`。当前锁文件没有包哈希，且来自 Python 3.9 的现有环境，不能宣称跨平台完全可复现。固件库与 PlatformIO 7.1.0 本轮重新取得，框架和编译工具链仍复用了本机缓存。许可字段来自安装包元数据并做了 SPDX 规范化，仍应在正式发布前由依赖审计工具和人工复核。

## 字体、图片和文案

- MiSans：只给小米官方下载/许可链接和本地导入器；原始字体、派生点阵、预览和固件不分发。
- Noto Serif SC、Inter、Lora：安装脚本从 Google Fonts 获取，官方目录标为 OFL；源 ZIP 不分发字体文件。
- 文泉驿：原镜像仓库没有许可证文件，已从公共安装流程移除；运行时使用 OFL 矢量字体回退。
- 历史 PNG 图标和截图：权属未证实，全部排除。
- 内置模式 JSON：大部分结构可追溯到 MIT 上游，但缺少精确基准提交；新增/修改部分仍需确认。
- 每日寄语：文件声明 `CC0-1.0`，但仍需发布者确认有权作出该声明；机器人位图与已核对的 MIT 上游一致。
- Waveshare：`EPD_4in26.*`、`DEV_Config.*` 保留其 MIT 风格头；`epd_wft.h` 与部分改编初始化序列仍需上游路径/版本证据。

## 顶层许可证方案

| 方案 | 适用范围 | 兼容性与前提 | 未决项 |
|---|---|---|---|
| 整体 `GPL-3.0-only` | 后端、工具、固件统一 | 对 GxEPD2 组合最直接；必须保留 MIT/BSD/Apache/LGPL 通知和对应源代码义务 | 用户需确认自己有权以 GPL 发布全部新增内容 |
| 后端/工具 MIT，固件 `GPL-3.0-only` | 按目录拆分 | 保留原上游 MIT；固件及二进制遵守 GPL；文档要清晰界定边界 | 维护复杂，公共头文件和共享资源需逐项归属 |
| 替换 GxEPD2 后再选宽松许可证 | 希望固件也使用 MIT/Apache | 必须彻底移除 GPL 依赖并重新验证驱动/构建 | 工作量大，Waveshare 改编和其他 LGPL 义务仍存在 |

不要使用 `GPL-3.0-or-later` 来描述 GxEPD2 本身；现有证据只支持 `GPL-3.0-only`。发布者可以将自己的代码许可为 “or later”，但组合分发结论仍需单独复核。

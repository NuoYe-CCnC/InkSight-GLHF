# 隐私与归档审计

## 实际扫描对象

扫描两次：临时构建中的完整候选树，以及由即将交付的 ZIP 全新解压出的完整目录。不是只扫描源目录，也不是只信任允许列表。报告不保存或打印匹配到的秘密值，只记录相对文件名和规则名。

覆盖：文件名与目录名、文本内容、macOS/Linux 用户绝对路径、微信标识、私钥块、OpenAI/GitHub/AWS/Google 常见密钥特征、JWT、URL 内凭据、MAC 地址、数据库/日志/备份/缓存/会话/状态目录、字体和生成字库、图片/预览/固件/本机动态库、嵌套压缩包、意外二进制、符号链接、ZIP 绝对路径与 `..` 路径穿越、重复 ZIP 路径。

另行检查了个人套餐日期和余额示例；代码注释中的历史个人日期已改成通用占位。候选中的 `member_config.json` 始终由打包器生成为空对象，不复制当前账户资料。Wi-Fi、坚果云、管理员、设备、API 密钥、数据库、运行上传、新闻缓存和历史状态不在允许列表。

## 明确排除

原始 MiSans、TTF/OTF/TTC/PCF、由 MiSans 生成的 C 头文件或点阵、预览 PNG/JPG、固件 BIN、图标 PNG、本机原生库、`.pio`、`.venv`、`.local`、测试缓存均不进入候选包。MiSans 校验/生成过程只在本机工作目录完成；临时文件权限和落盘路径受限，打包器再次按名称、路径和类型排除。

## 局限

规则扫描不能数学证明“没有任何秘密”，无法识别所有新型或加密凭据，也不能证明代码、文案或图片的著作权。扫描 0 项只表示本规则集没有命中，不等于法律合规认证。外部收据和候选 ZIP 仍需发布前人工抽查。

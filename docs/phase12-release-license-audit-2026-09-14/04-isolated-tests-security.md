# 隔离测试与安全边界

## 必测路径

所有发布验收从最终 ZIP 解压到新临时目录开始：Python 导入、静态文件、配置示例、迁移、管理恢复工具、首次 root、无默认管理员密码、loopback 限制、CSRF、草稿版本保护、配置导出脱敏、秘密文件 `0600`、无付费 Key 启动、管理端未知值显示 `--`、无新闻 Key 的本地每日寄语、MiSans 缺失提示、本地 MiSans 私有导入后无候选污染、首个硬件环境依赖解析和固件构建。

本轮允许复用本机 Python/PlatformIO 缓存，但必须在结果中写明；这不能替代全新电脑安装。固件只构建，不烧录。后台只在隔离目录和临时端口启动，不重启生产服务。隔离启动显式设置 `INKSIGHT_OFFLINE_STARTUP=1`，保留数据库/静态初始化但关闭后台网络轮询；测试禁止真实付费模型/新闻请求、真实云端写入和外部秘密轮询。

## 安全审计结论边界

- 管理端、初始化和恢复入口应仅接受 loopback 客户端/Host/转发来源；首次 root 创建成功后初始化入口立即关闭。
- 修改操作要求登录会话和 CSRF；草稿带基准版本，旧标签页不得覆盖新配置。
- 配置导出必须递归移除密码、密钥、令牌、Authorization、Cookie 和凭据；私密配置写入权限为 `0600`。
- 字体导入拒绝符号链接、非字体文件、异常大小、错误家族/字重和缺字；仅写 `.local` 与被忽略的固件派生文件。
- 坚果云/WebDAV 会接触设备拉取内容和 Basic Auth 凭据，服务运营方与网络路径属于信任边界；开源包不包含当前账户。
- 新闻标题、摘要和链接在运行时来自第三方站点；开源代码许可不授予转载新闻内容的权利，发布者需核对各来源条款和合理展示范围。
- XAUS/`gold-api.com` 的接口可用性、速率和再展示条款未见仓库内固定许可，应视为外部服务依赖，不得承诺永久免费或永久可用。

## 本轮实测

- 源工作区完整回归：827 项通过，2 个既有依赖警告（本机 LibreSSL 与 urllib3、DashScope 弃用提示）。
- 实际 ZIP 全新解压后随包专项测试：10 项通过；未在封存候选目录运行测试。
- 隔离 HTTP：无任何付费 Key并设置离线启动开关后正常启动；跨站 root 初始化返回 403，首次创建成功，第二次返回 409；登录、CSRF 和脱敏配置读取通过；生产 8080 服务未重启。
- MiSans：未导入时固件明确因缺少 `fonts_misans_16.h` 失败；在解压副本内从本机私有字体导入后构建成功。候选目录和 ZIP 摘要在前后保持不变。
- 固件：`epd_426_ssd1677_s3_n32r16` 使用 PlatformIO espressif32 7.1.0、Arduino-ESP32 `3.20017.241212+sha.dcc1105b`；RAM 96,648/327,680，应用 Flash 3,857,825/6,291,456。没有烧录。
- 依赖来源：PlatformIO 7.1.0 和六个固定库本轮重新下载/解析；Arduino 框架及两套编译工具链复用本机缓存，因此仍不是“全新电脑、零缓存”证明。

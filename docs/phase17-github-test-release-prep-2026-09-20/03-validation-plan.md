# 验证计划

日期：2026-09-20

1. 检查中英文 README 和安装/Release Notes 的关键口径一致。
2. 解析公开 Markdown 相对链接，确认目标都存在；扫描个人绝对路径和敏感占位。
3. 核对文档命令引用的入口都在最终候选允许列表中。
4. 核对默认新闻源、显示开关、四条寄语与 GPL 许可字段。
5. 运行阶段 17 文档专项、既有发布专项和正确入口全量回归。
6. 连续两次由构建器生成候选，比较 ZIP 与目录树摘要。
7. 对实际 ZIP 全新解压后运行随包发布专项，并复核隐私、字体、二进制、危险路径和许可一致性。

本轮不重新执行实机刷写、生产服务重启或真实外部 API 验收；结果中必须把这一点列为未测，而不是写成通过。

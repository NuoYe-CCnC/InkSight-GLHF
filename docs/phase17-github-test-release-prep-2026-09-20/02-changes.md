## 关键口径

- 只承诺 ESP32-S3 N32R16V + 微雪 4.26 英寸 SSD1677 800×480 与 macOS ARM64/Python 3.9 验证基线。
- 远程新闻默认关闭；无来源/Key 时显示四条已确认寄语，不承诺长期不重复。
- MiSans 和派生字库/预览/固件不分发；软件许可不替代字体或新闻内容许可。
- OpenAI API 月消费是组织 UTC 自然月消费，不是余额或个人 Codex 全部开销；Admin Key 只留在本机后端。
- 主机休眠与设备唤醒是两条不同链路；不宣称睡眠期间准时出刊，也不宣称 2000 mAh 一周续航。
- 自动测试、用户确认、未测范围分开表述；本轮不冒充新的实机验收。

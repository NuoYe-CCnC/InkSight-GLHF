# 新闻源发行策略与实现

日期：2026-09-14

本轮采用保守发行策略，不作法律裁决：新安装的 IT之家、量子位、Ars Technica、The Verge、TechCrunch、OpenAI News 六个远程源全部关闭。配置入口保留，部署者逐源核对条款并取得所需授权后才能开启。

## 行为

- `news_digest.source_enabled` 是逐源开关，发行示例全部为 `false`；旧 `sources` 字段作为兼容允许列表保留。
- 旧配置只有 `sources` 时，在内存中转换为等价开关，不改原文件、不覆盖用户已经明确选择的来源。
- 获取 RSS、读取旧缓存候选、候选排序、模型提示词、自动补刊和手动出刊都使用同一有效来源列表。
- 缺少 API 密钥时先回退本地每日寄语，不发起 RSS 请求；全部远程源关闭时同样不联网、不调用模型。
- 空候选不会被误判为“重新读取全部缓存”，不会发布虚假的新摘要成功状态。
- 历史已发布内容不追溯修改；仅阻止禁用来源进入未来的新提示词和新刊物。

## 用户界面与元数据

本机管理页增加紧凑的六来源开关和许可提醒，不改 800×480 墨水屏版式。Web 内容管理页对模型生成内容显示“AI 摘要”，并从已发布事件元数据中显示来源链接与报道时间。归因和链接只用于透明度，不代表已经取得复制、改写或再发布许可。

## 未触碰范围

本轮没有写生产 `inksight_config.json`、密钥、运行状态、服务、设备或 GitHub；只修改发行默认值、兼容迁移、运行路径、管理页、测试和候选构建资料。

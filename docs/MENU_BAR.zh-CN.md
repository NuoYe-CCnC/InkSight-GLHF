# 菜单栏与本机配置（test.9）

## 入口与生命周期

首次、手动和登录启动均静默驻留右上角 Is 菜单，不打开窗口或浏览器，不抢焦点。点击“打开配置”才打开本机管理网页。未配置时菜单提示“待配置”；“运行详情”可主动打开原生状态窗口。菜单创建失败时保留窗口，避免失去入口。

关闭网页或状态窗口不停止后台。“暂停自动服务”阻止新自动采集、出刊、发布，管理页仍可访问，已接纳任务安全收尾。“退出 InkSight”（或应用内 Command-Q）先暂停再等待在途工作；固件写入、状态损坏或超时会阻止退出，并提供详情，不强杀工作线程。最长等待约 240 秒。

最近成功发布时间指上传并回读验证成功，不等于设备已刷新。后台运行不能使睡眠中的 Mac 继续计算，本应用不修改系统睡眠设置。

已有系统登录项按原路径保留；新安装不自动注册，用户可在菜单启用。真正随下一次系统登录启动须实际登录验证。

## 免密码不等于匿名管理

仅桌面 App 模式停用旧账号登录、创建管理员、注册与重置密码入口，以及旧 JWT cookie/header 会话。旧账户表、业务数据库、API Key、设备令牌、内部 ADMIN_TOKEN 和云端凭据均保留，不物理清除。认证协议版本为 desktop-session-v1，随桌面版本升级切换，无数据库结构迁移；升级前仍须备份数据库及配置。

App 使用每次运行的内部凭据申请 60 秒有效的一次性启动票据。票据放在 URL fragment，不进入 HTTP 请求路径；网页脚本立即用 replaceState 清除，再同源 POST 换取最长 8 小时的 HttpOnly、SameSite=Strict、host-only 会话。票据和会话仅存后端内存，后端重启全部失效；不保存到网页存储。过期后从菜单重新打开，无需密码。

test.9 每次菜单打开使用新的 `/desktop/config/<随机标识>` 页面路径，资源使用内容哈希版本，避免旧文档、旧脚本缓存或仅改变 fragment 的同文档导航沿用旧登录界面。随机路径不是认证凭据，不能据此访问配置。页面响应带 `X-InkSight-UI: desktop-session-v2`；会话 cookie 协议不变。此措施与用户实际入口验收是两回事，不能仅凭接口健康或构建成功宣称 root 问题已验收。

## 菜单栏 Codex 七日剩余

现有 B2 Is 图标右侧显示短整数，如 `36%`。只使用本机已有 `ai.codex` 缓存中的 10080 分钟窗口，剩余值为 100 减已用百分比；0% 是有效耗尽。系统菜单栏字号、同一菜单点击区域，预留 100% 宽度以减少跳动。不增加 Codex 进程或上游采集频率，配置网页关闭时仍更新。

App 每 15 秒异步读取带本次运行内部凭据的本机只读接口；未授权或仅持网页会话均不可访问。启动未知、读取失败、非法值、非七日窗口、非本机来源、账户变化或数据过期时只显示 ASCII `-`。本机登录账户仅做哈希比对，不返回账号或凭据。菜单详情提供来源、最后成功时间与原因。

过期阈值沿用 `ai_source_policy().codex.stale_after_s`，即配置采集周期最大值乘允许漏采周期数；默认允许三周期。暂停后不延长旧样本有效期；失败和菜单读取不更新最后成功时间。恢复有效采集后在下一次本机读取时显示正常数值。后端重启、乱序响应、退出期间回调都不能恢复已失效数字。

服务仅绑定 IPv4 127.0.0.1，不监听 LAN、通配地址或 IPv6。请求校验对端、精确 Host/端口、Origin/Referer、Fetch Metadata，拒绝代理头与跨源请求。配置写操作仍要求 CSRF token，烧录等危险操作保留确认。浏览器会话不能代替设备令牌、内部 Bearer 凭据或 App 生命周期令牌；匿名访问只看到入口提示，不能读取配置或维护 API。

HTTP loopback 不启用 Secure cookie，必须保持本机绑定和来源限制。本机已获执行权限的程序与操作系统管理员属于可信边界；这不是防御恶意本机软件的沙箱。远程配置不支持，禁止改成 0.0.0.0 或反向代理公开。

参考 [OWASP CSRF 防护](https://cheatsheetseries.owasp.org/cheatsheets/Cross-Site_Request_Forgery_Prevention_Cheat_Sheet.html)与[会话管理](https://cheatsheetseries.owasp.org/cheatsheets/Session_Management_Cheat_Sheet.html)，不将本说明当安全认证。

## 视觉与构建

配置功能与导航保留，中性灰配色跟随系统明暗；不使用 ChatGPT 商标或官方身份。本次配色不改变实体墨水屏布局。原生窗口使用系统语义色。

B2 原图保持不变，菜单栏从同一字形生成单色模板，18 逻辑点对应 Retina 36 物理像素。公开构建仅含经固定哈希校验的图标，不含个人配置、MiSans 或带字体固件。当前 macOS arm64 构建为 ad-hoc 签名，未经过 Apple Developer ID 签名或公证。

# InkSight-GLHF 首个测试版 Release Notes（归档草案）

> 本草案已由 [`v0.1.0-test.1` 正式测试版说明](releases/v0.1.0-test.1.zh-CN.md)取代。后端 API 的 `1.1.0` 不是项目发布版本号。

## 概要

这是 InkSight-GLHF 的首个公开测试候选：面向 ESP32-S3 N32R16V 与微雪 4.26 英寸 SSD1677 800×480 黑白墨水屏，包含本机后端、网页管理端、`AI 用量`和`今日关注`两套面板、配置工具及固件源码。

## 本候选包含

- 本机 root 管理、配置草稿/校验/确认应用和双页预览。
- Codex 窗口信息、DeepSeek 余额/本项目 Token、可选的 OpenAI 组织 UTC 月消费显示。
- XAUS 国际现货金价换算与北京时间当日首条有效报价基线。
- 新安装远程新闻源全部关闭；无 Key/无来源时使用四条 GPL-3.0-only 本地寄语。
- MiSans 本地校验/导入/字库生成工具；发行包不含字体或派生字库。
- 针对唯一已验证硬件目标的构建与受控空白板/更新刷写代码。
- GPL-3.0-only 顶层许可、第三方通知、SBOM、双语说明、安全与贡献文件。

## 已验证

- macOS ARM64 + Python 3.9 哈希锁依赖安装和隔离导入。
- 2026-09-14 基线全量自动回归 862 项通过、2 条既有依赖警告；候选 ZIP 隔离专项 45 项通过。
- 候选包隐私、危险路径、字体/二进制排除、四条寄语精确性和可复现构建检查。
- 已验证固件目标：`epd_426_ssd1677_s3_n32r16`。

## 用户已确认

- 四条发行寄语的原文和 GPL-3.0-only 处理选择。
- `AI 用量`页当前定稿方向；`今日关注`页采用通栏信息结构与两条横线间的用量布局方向。
- 设备曾显示 `API 本月消费 0.00 USD`；这只证明当时显示链路，不代表持续轮询、跨月或离线补拉已经验收。

## 未完成或不承诺

- 本轮仅准备文档和候选包，没有重新烧录设备、重启生产服务或调用真实付费 API。
- Windows、Linux、Intel Mac 与其他屏幕/开发板没有完成同等级整套验收。
- 新电脑首次下载 PlatformIO CLI/平台依赖尚未形成跨平台哈希锁验收。
- macOS 睡眠期间不能保证按时出刊；唤醒恢复不保证补全每个错过期次。
- 2000 mAh 一周续航没有规范实测，不作为测试版能力。
- 远程新闻源默认关闭；启用前由部署者逐源审查许可、归因、链接、隐私和服务条款。
- 四条本地寄语会重复，不承诺大量内容或全年不重复。

## 升级提醒

升级源码不会自动覆盖现有配置。先备份私有配置、数据库和运行状态；旧配置先执行 `migrate --dry-run`。已有设备更新只应在分区表完全匹配时走受控 `update`；新板 `fresh` 只接受真正空白的关键区域。详见[安装与恢复指南](INSTALLATION.zh-CN.md)。

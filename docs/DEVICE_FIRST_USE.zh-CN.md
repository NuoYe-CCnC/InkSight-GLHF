# 设备首次使用与固件准备中心

本页对应公开测试版 test.18 的图形准备流程，下载以[同版Release资产](DOWNLOAD.zh-CN.md)为准。支持Apple Silicon/macOS26.5+、ESP32-S3 N32R16V及微雪4.26英寸黑白SSD1677/800×480。实际主机测试26.5.2，本机迁移、现有板兼容升级及人工刷新确认已通过；空白板、真实回退、另一台Mac/Gatekeeper和重新登录自启动仍未验收，不承诺所有用户一次成功。

## App 用户从哪里开始

1. 校验下载包摘要后解压完整 App，按系统正常方式打开。App 尚未公证；若系统阻止，应由你判断来源并按系统安全流程处理，不要关闭系统保护。此项目不提供全局移除安全限制的脚本。
2. 从菜单栏 Is 选择“打开配置”。App 本机入口不需要 root 账号或默认密码。源码模式的管理员流程是另一条路径。
3. 总览点击“设备首次使用 / 固件”，或进入“维护”。准备中心逐项列出主机、字体、工具、空间、配置、Wi-Fi、云端、网络依赖和 USB。USB 未连接不会阻止构建，也不要求你先知道 MAC。
4. 填写并应用配置、导入字体、准备工具的先后顺序不限。只有点击对应按钮才开始导入或下载。前两步不查额度、不调用付费模型、不发布云端文档。

## 字体由用户提供

从[小米官方 MiSans 下载页](https://hyperos.mi.com/font/en/download/)取得字体并阅读适用许可。在你自己的电脑解压官方包，选择简体中文静态 Regular 与 Bold 单独 OTF 或 TTF 文件；文件名可以不同。MiSans4.003原文件实测OS/2字重为330/630，校验同时支持命名正确的330/630与标准400/700，不把CSS常见数值硬当字体文件值。不要选TTC、VF可变字体、WOFF或只覆盖一部分文字的网页子集。

界面每份文件限制 32MiB；后端验证实际文件头、字体家族、静态字重及完整必需字形，再生成面板所需的 12 份字库。整个新生成集通过校验后才切换；失败或取消继续保留原可用字库，不静默换字体。取消会在当前单份字库完成后生效，单份生成设有三分钟超时。

字体、字库头与带字体的固件均留在用户私有目录，不写签名 App，也不随开源包分发。GPL-3.0-only 是项目软件的许可，不是对第三方字体的再分发授权。

## 工具是按需安装，不是 App 自带完整工具链

“下载并准备工具”会利用 App 内置 Python 3.11 创建私有虚拟环境，安装固定版本 PlatformIO Core 6.1.19、espressif32 7.1.0 和受支持目标的固定依赖。Python 工具使用独立的 SHA256 锁文件；平台、框架、编译器和库按固定版本下载，并记录本地文件摘要和版本清单。

- 仅从 PyPI / PlatformIO 官方注册源及其分发服务获取依赖，不运行远程 shell，不需要 sudo，不修改 Homebrew 或系统 Python。
- 不借用 `~/.platformio`、开发者 `.pio-core` 或已有生成字库。失败可重新点击准备，旧可用环境不会被半成品替换。
- 首次可能下载较大文件，至少保留4GiB可用空间。离线、TLS、版本或空间检查失败会显示原因，不绕过校验；网页关闭不会等同于取消。
- 工具准备可取消自己的下载进程；字体在单份生成边界取消。USB 写入关键阶段不能强行取消或拔线，应等待校验结束。

工具版本锁在 [requirements-firmware-py311-macos-arm64.lock](../requirements-firmware-py311-macos-arm64.lock)；esptool的9项附加依赖另有 [SHA256锁](../requirements-esptool-py311-macos-arm64.lock)，不沿用上游安装脚本的浮动版本下载，其他未批准的安装钩子会被拒绝。它们与 App 后端依赖锁分开。工具本身不嵌入公开 App，新用户按需下载仍须遵守各工具原许可，不能将它们视为统一改授 GPL。

## 配置与首次绑定

在“API 与账户”填写 Wi-Fi 与坚果云/WebDAV，再去“设备与运行”应用草稿。Wi-Fi 完整列表的先后就是新板连接优先级。没有新闻 Key 时使用本地寄语；不要为了准备字体或固件随意启用付费来源。

USB 使用支持数据的线。点击“查找 USB 设备”只枚举串口；“只读识别”会短暂复位板卡，读取芯片/MAC和容量，不写 Flash。核对设备指纹后才能确认绑定，MAC 不需要手工抄写。新用户空目标由 App 自动读取已确认绑定；已有发布目标不会被静默替换。

芯片与 Flash 容量检测不能证明屏幕型号、接线或 PSRAM 型号正确，仍须核对实物。唯一受支持接线见[安装指南](INSTALLATION.zh-CN.md#5-接线)，特别是 DC13 / RST14 / BUSY4 / PWR5。不能用软件预检替代接线检查。

云端凭据“已填写”不表示已经联网。在 Is →“运行详情”先点“刷新状态”，再主动“测试云端”；该测试上传/回读/清理独立测试文件，不调用付费模型。只有你明确点击“启动发布”才运行发布循环。新用户没有已发布文档时，预览应为空；“高级诊断”是缺数据占位，不能冒充实屏或发布记录。

## 构建、识别、备份与写入

准备条件全部就绪后“构建固件”。构建在私有 workspace，不写 App 或公开源码；会冻结配置、源码、字体和工具指纹。配置或准备环境改变后，旧构建失效。构建完成显示版本与 SHA，不表示已经烧录。

选择唯一 USB 目标与模式后，执行只读识别/备份，页面显示进度。读取过程可能需要几分钟，不能因为暂未完成就反复创建任务：

| 当前设备 | 正式流程 |
|---|---|
| 真正全空白板 | 读取全部32MiB确认空白，备份并校验后才提供写入确认 |
| 本项目兼容已有板 | 匹配分区、原应用标识、NVS配置版本与安全状态，备份引导/NVS/OTA/双应用/文件系统 |
| 未知或厂家预置板 | 拒绝自动清空或套用兼容升级，不能因为“新买的”就绕过空白检查 |

未知板可以先联系厂家核实原固件和恢复方式，或使用真正空白的备用板；本版不提供自动擦除厂家程序的入口。只读核对失败时没有获得写入授权。

最终确认会列出设备指纹、模式、固定硬件、镜像摘要、备份结果、写入范围与五分钟确认期限。确认只能使用一次；执行前再次识别目标并备份最新状态。后续写入失败不能靠重复提交旧确认来续刷。

兼容升级动态确定当前槽和非活动槽，只写非活动应用，完整回读后再写一个替代 OTA 扇区。原活动应用、Wi-Fi顺序/密码、设备身份、NVS与文件系统保留；固件首次启动也不把编译 Wi-Fi 快照覆盖到已有设置。**因此在主机改 Wi-Fi 后，普通兼容升级不会顺带替换设备网络。**更换设备网络应使用经确认的配网流程，不能靠升级隐式覆盖。

首次安装只写引导、分区表、OTA初始化与app0，不执行全片擦除。若首次写入中断，设备已经不再是空白板，流程会拒绝假装它仍为空白；保存记录，重新识别实际状态并联系维护者，不要自行擦除或套用其他板的固件。

## 验收层级与回退

准备中心分别记录“编译完成”“写入回读通过”“设备联网回执”“人工实屏确认”。USB 设备回执只在实际取得并解析网络 JSON 后发出，匹配本次构建与物理连接；它不证明墨水屏已正常成像。没有可靠设备回执时会保持“尚未确认”，不拿后台健康接口代替。用户必须观察画面后主动记录实体屏确认。

兼容更新产生的正式 Web 备份可用于“核对并回退上次更新”。回退重新检查同一设备、原备份、当前启动项及旧应用；只恢复已校验的启动扇区，不恢复陈旧 NVS、Wi-Fi、文件系统或主机账本。过期确认、目标变化、备份损坏或其他更新改过启动项均拒绝写入。没有匹配旧版心跳时，保持“已校验，待实体屏确认”。

App 退出会等待关键任务；后端意外中断后不会自动重试 USB 写入。重启恢复记录不等于硬件已安全：应重新识别，保护区不确定时保留备份并停止自动复位。不要用整片旧备份覆盖新的消费账本或设备设置。

## 源码高级路径

App 用户不需要 Python 命令、root账号或内部目录知识。源码用户若使用新的图形准备中心，应自行建立 Python 3.11 后端并按 `requirements-py311-macos-arm64.lock` 安装依赖，再按源码的本机管理员流程进入；Python 3.9 文档保留的是旧版源码基线，不是本版图形工具准备的解释器要求。

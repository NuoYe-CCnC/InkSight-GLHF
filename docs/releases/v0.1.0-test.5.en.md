# InkSight-GLHF v0.1.0-test.5

Public pre-release, 2026-09-30. Apple Silicon Mac app and matching source; no new firmware binary or required device flash.

This release completes host duties missing from the test.4 desktop publisher. The existing opt-in network switch also enables device gold/news request queues and bounded wake recovery. Queue requests use the selected loopback port and finish before publication. Existing source authorization, issue deduplication and model-call budgets remain in effect.

Import preserves legacy `agent_policy.json` publication/Codex intervals, private calendars/messages and user-owned MiSans fonts and glyph-width data. These are local user data, never included in release assets. Without a legacy policy, the defaults remain a 60-second publication check and 30-minute quota read.

Network failures keep the publisher alive. Unexpected backend exit retries at most three times. Closing the app stops its backend and child jobs; reopening probes the cloud and resumes previously enabled publishing. Explicitly stopping publication cancels that preference. Native wake notifications and a monotonic sleep-gap check use the existing bounded host-recovery API only when network tasks are enabled. The app creates no login item.

161 backend tests cover queue ordering/ports, polling policy, failure recovery, child cleanup and data preservation. Isolated startup, exit/port release, relaunch, backend restart and signature checks were run on Apple Silicon macOS 26.5.2. These immediate checks do not qualify a long-running soak.

Stop the previous publisher and its automatic restart before importing a stopped snapshot. Preserve configurations, SQLite databases, news/call-budget ledgers, gold baselines and request deduplication. Separate local locks cannot arbitrate a shared cloud device. Rollback must stop the app first and retain its newer compatible state rather than reverting budgets or issue records.

The app remains ad-hoc signed, without Developer ID signing or notarization. Release assets exclude production secrets, device identities, private state and MiSans. Experimental firmware rollback remains unqualified for physical writes.

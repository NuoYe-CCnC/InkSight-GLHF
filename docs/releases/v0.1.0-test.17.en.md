# v0.1.0-test.17 — graphical preparation and verified publication previews

Public test release / **pre-release**, 2026-10-27. This combines development since public test.9; intermediate local candidates were not separately published.

Download the [ordinary Apple Silicon App](https://github.com/NuoYe-CCnC/InkSight-GLHF/releases/download/v0.1.0-test.17/InkSight-macOS-arm64.zip), or the separate [source archive](https://github.com/NuoYe-CCnC/InkSight-GLHF/releases/download/v0.1.0-test.17/InkSight-Source.zip). See the [complete Chinese release notes](v0.1.0-test.17.zh-CN.md) and [checksums/asset guide](../DOWNLOAD.zh-CN.md).

Changes include locally supplied MiSans import, explicit pinned-tool downloads, configuration/build readiness checks, stale-confirmation rejection, concurrent/multi-tab deduplication, bounded compiler cancellation/retry, full GET-verified publication snapshots with two-page PNG previews, optional default-off experimental Codex forecasts, and guarded compatible-board updates. The latest test.17 fix explicitly hard-resets the ESP32-S3 when resuming application execution; reads/backups/writes/readbacks still finish without resetting. An esptool success code alone is not a network or screen acknowledgement.

561 tests passed with no skips in the fully provisioned private validation environment; one existing dashscope deprecation warning remains. Another 10 build-controller and 5 preview-controller scenarios passed. Private fonts and successful-publication baselines are excluded from the release, so missing optional test resources must be reported as skips. Production App migration, preserved state, single-Is operation, password-free local configuration, normal publication/readback and one existing-board compatible upgrade with human screen refresh confirmation were validated.

Fresh-board flashing, actual rollback, a second Mac/Gatekeeper first launch, next-login startup, exhaustive physical field inspection and long-running page switching remain unverified. App minimum is Apple Silicon/macOS26.5, actually tested on26.5.2, bundled CPython3.11.15. Ad-hoc signing is **not Apple notarization or Developer ID signing**. The supported MCU/panel is ESP32-S3 N32R16V plus Waveshare4.26-inch monochrome SSD1677/800×480. No measured one-week claim is made for2000 mAh.

Exit the old App normally and preserve current private data before replacing the complete App at the same path. Compatible firmware need not be reflashed to match the App version; this final host-side fix does not require another device update. Additional device-side features may require a separately checked, correctly targeted firmware build. Rollback must preserve records added after upgrading; never overwrite them with an old ledger or NVS/filesystem backup.

Project-owned code/messages remain GPL-3.0-only; third-party notices and bundled dependency licenses remain intact. MiSans is obtained/imported locally from Xiaomi's official site. No fonts/generated glyphs, private firmware, credentials, device identities, snapshots, account data or backups are distributed. Remote news and experimental forecasts are off by default; forecasts are not an account guarantee. A sleeping Mac cannot guarantee scheduled collection/publication. No ready-to-flash firmware binary is provided.

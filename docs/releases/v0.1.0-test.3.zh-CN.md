# InkSight-GLHF v0.1.0-test.3

发布日期：2026-09-29
状态：公开测试版（pre-release）
范围：首个独立 Apple Silicon Mac 应用；不含新固件二进制，无需因本次主机更新刷屏。

## 本次新增

- `InkSight.app` 内含 Python 3.11.15、后端和锁定依赖。只在 Apple Silicon、macOS 26.5.2 验证；运行时无需用户另装 Python、Homebrew 或克隆仓库。
- 本机控制窗口提供服务启动/停止/重启、端口选择、管理员状态、采集汇总文档检查、可选网络采集开关、WebDAV 显式测试和发布循环控制。新安装默认不启用后台网络采集，不自动调用付费模型。后端只监听 `127.0.0.1`。
- 首次运行建立当前用户专属的数据目录，自动生成独立本机令牌；每个版本分目录存放，升级前验证并保留旧版目录。旧源码数据只能经用户主动选择、预览、备份与确认后导入，不自动读取生产部署。
- App 正常退出或意外终止后，由它启动的后端及发布循环停止。端口占用不接管其他服务。云端上传/回读成功不等于实体设备已经刷新。
- 同版继续提供经允许列表、隐私扫描和解压复核的 `InkSight-Source.zip`；它是源码包，不是安装器。
- `APP_COMPONENTS.json` 列出应用内 CPython 与 84 个 Python 发行包的版本、可用许可证元数据及包内通知文件；原有 `SBOM.json` 仍是早期 Python 3.9 源码部署审计快照，不冒充本 App 的清单。

## 下载、安装与限制

先读[文件选择与 SHA-256 校验](../DOWNLOAD.zh-CN.md)，然后按[Mac App 安装说明](../APP_DESKTOP.zh-CN.md)操作。**App 只有 ad-hoc 签名，没有 Apple Developer ID 签名或公证**。系统可能阻止下载后的首次打开；不要关闭系统安全功能。只有使用者核对来源与校验值后，才自行决定是否按 Apple 官方指引在“隐私与安全性”处理提示。这不是“任意 Mac 双击即用”的正式版。

已完成 139 项本仓库后端/发行相关自动测试，以及隔离首次启动、本机健康返回、首位管理员创建、中文/空格路径和只读 App 目录、重复启动/意外退出、配置与状态迁移测试。尚未完成第二台全新 Mac、其他系统版本、真实坚果云账号和实体屏的本版端到端验收；不能把自动测试替代实机结果。Mac 休眠时不能保证定时采集和出刊。

## 升级与回退

既有源码部署不会被新 App 自动修改。迁移前保存私有配置、数据库和状态的同一时点备份，并停旧服务；在 App 内明确选择旧源码目录导入后逐项核验。后续 App 版本会复制受管数据到新版本目录并保留旧目录，但用户仍须自行备份。回退需要停止新 App，恢复对应旧版程序和旧版状态；本版没有一键回退按钮。设备固件未改变，不需要因此重刷。

源码不含生产密钥、账户、真实设备 MAC、MiSans 原始字体或派生字库、生产缓存/数据库。安全问题请走[私密漏洞报告](https://github.com/NuoYe-CCnC/InkSight-GLHF/security/advisories/new)。

# InkSight-GLHF v0.1.0-test.5

2026-09-30，公开测试版。提供 Apple Silicon Mac App 与同版源码，不含新固件二进制，主机迁移无需重新烧录。

test.4 的 App 可以发布页面，但尚未接手源码总管的全部日常任务。本版补全这些职责：

- 允许后台网络采集的开关同时控制设备金价/新闻请求队列与主机唤醒恢复。队列使用 App 所选端口，先处理再组成页面；默认仍关闭，启用后沿用已有来源授权、出刊去重与模型调用预算。
- 导入时保留旧 `agent_policy.json` 的发布周期、ChatGPT 开启/关闭时的 Codex 采集频率。没有旧策略时仍使用 60 秒发布检查与 30 分钟额度采集。读取额度不调用模型，不消耗手动重置机会。
- 网络或后端暂不可用不会永久终止发布循环。后端意外退出最多自动重试 3 次；关闭 App 会停止其后端、发布器、队列和恢复任务，不留下付费子进程。再次打开会在云端测试成功后恢复上次启用的发布；主动点“停止发布”会取消恢复。
- 接收原生 macOS 唤醒通知并检查连续时钟的休眠缺口，调用已有的受限补拉接口。离线模式不调用该接口；这不能保证主机休眠期间及时出刊。
- 旧数据导入补充私有日历、寄语、采集策略、MiSans 原字体与设备字宽数据。这些只在本机授权导入，不进入公开 App 或源码附件。

161 项后端测试通过，覆盖队列顺序/端口、动态频率、网络失败重试、超时子进程清理与数据保留。App 在同一台 Apple Silicon、macOS 26.5.2 上通过隔离启动、退出/端口释放、再次启动、后端意外退出恢复与签名校验。自动化和即时核验不等于长期运行验收；本版不声称已完成长期稳定性观察。

迁移现有生产部署前，必须先停止原发布者及其自动重启，保存停止后的配置、数据库、出刊/调用预算/金价/请求去重状态，再导入 App。两套数据目录的文件锁不会替你仲裁同一云端设备。回退也应先停 App，并保留它运行期间新增的合法状态；不要用旧快照倒退预算或出刊记录。详见[升级说明](../UPGRADE.zh-CN.md)。App 不会自动创建登录启动项，关闭最后一个窗口会退出并停止服务。

App 仍为 ad-hoc 签名，未获 Apple Developer ID 签名或公证。源码不含生产凭据、真实设备身份、私有数据库/配置或 MiSans 字体。实验性网页固件回退仍只有模拟与只读预检，尚未完成本版实机写入/回退验收；本版不要求刷写日用设备。参见[下载校验](../DOWNLOAD.zh-CN.md)、[支持矩阵](../SUPPORT_MATRIX.md)及[回退边界](../FIRMWARE_UPDATE_ROLLBACK.zh-CN.md)。

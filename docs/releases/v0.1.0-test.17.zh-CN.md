# v0.1.0-test.17 — 图形准备、发布预览与安全升级

2026-10-27。**公开测试版（pre-release），不是稳定版。** 本版汇总公开 test.9 之后的本地开发成果；test.13/15/16 是开发阶段，未分别作为公开发行。

## 下载与适用范围

- 普通 Mac 用户：[InkSight-macOS-arm64.zip](https://github.com/NuoYe-CCnC/InkSight-GLHF/releases/download/v0.1.0-test.17/InkSight-macOS-arm64.zip)，先按[下载校验指南](../DOWNLOAD.zh-CN.md)核对同版 SHA256。
- 开发者：[InkSight-Source.zip](https://github.com/NuoYe-CCnC/InkSight-GLHF/releases/download/v0.1.0-test.17/InkSight-Source.zip)。项目整理的源码资产与 GitHub 自动生成的源码压缩包不同。
- App 内置 CPython3.11.15；最低 Apple Silicon / macOS26.5，实际测试26.5.2。不是 Intel、Windows 或 Linux 安装器。App 为 ad-hoc 签名，**无 Developer ID 签名或 Apple 公证**。
- 固件支持 ESP32-S3 N32R16V（32MB Octal Flash / 16MB Octal PSRAM）与微雪4.26英寸黑白 SSD1677 800×480，目标 `epd_426_ssd1677_s3_n32r16`。其他历史环境不等于支持。

## 从公开 test.9 到本版的主要更新

1. **新用户图形准备。** Is → 打开配置 → 设备首次使用/固件：导入用户合法取得的 MiSans 静态 Regular/Bold OTF/TTF，校验样式并生成私有字库；按需准备固定 PlatformIO、编译器和库；逐项检查配置、Wi-Fi、WebDAV、空间与工具。第一次工具下载需要联网且由用户明确启动，不要求给 App 安装系统 Python 或创建 root。修复实际 MiSans 权重识别、原生工具校验和 BUSY/ADC 共用时的编译保护。
2. **配置、构建及恢复保护。** 配置应用后自动重新核对，旧确认绑定输入/源码/字体/工具指纹；并发与多标签去重，迟到响应不覆盖新状态。构建支持受控取消和重试，刷新与本机服务恢复后重查；中文显示失败、取消及不可达，不能沿用虚假的就绪结果。取消构建不等于取消设备写入。
3. **真实发布快照预览。** 保存完整文档必须先完成上传与GET回读SHA256核对；总览可查看/导出800×480的AI用量和今日关注。渲染使用该文档的发布时刻，缺项不拼入别的缓存。连接验收使用独立唯一对象、创建保护、回读和临时文件清理；完整验收对象有意保留，明确不是设备轮询文件。它不启动付费模型或自动发布，也不代替设备实屏回执。
4. **可选 Codex 额度预告及多来源状态。** 新增来源适配、严格解析、到期过滤和视图一致性保护，保留实际7日额度与预告的独立判断；有效预告可临时优先使用右侧空间，失效后恢复用户可选信息。菜单实验星号须满足开启及有效事件条件。**新安装预告默认关闭**；实验来源可能缺失/变化，公开事件和估计不是个人账户重置保证，也不改变官方额度。未知值不冒充零。
5. **保留设置的兼容升级与恢复应用。** 识别实际设备、分区与支持的NVS配置，备份引导/NVS/OTA/双应用/文件系统；仅写非活动应用，完整回读并核对保护区域后切换单个OTA扇区。保留有效的设备Wi-Fi顺序/密码、身份和设置，不用编译默认值隐式覆盖。最新test.17修复在主机工具：固定esptool4.11的 `run` 默认不重启，结束时现明确 `hard_reset`；读/备份/写/回读阶段仍为 `no_reset`。占用串口拒绝复位，命令失败不报告成功。已验证的串口桥路径不等于原生USB-JTAG等所有接口都已验收。

## 升级已有安装

先备份最新私有数据，从Is正常退出，确认原发布者退出；校验新ZIP，替换**同一路径**的完整App再启动。正常迁移保留受管数据与旧目录，检查只剩一个Is、配置入口、真实额度与原发布服务。不得把QA变体或独立测试WebDAV配置当生产配置。操作详见[升级指南](../UPGRADE.zh-CN.md)。

**已有固件若兼容，不因电脑App版本变为test.17而要求重复烧录。** 本次本机最终更新只改变主机恢复应用流程，已验证的设备固件保持原样。公开test.9设备若要使用新增设备端预告等功能，须另核对固件能力和精确板型，再选择是否受控构建/升级；不自动刷写未知设备。首次烧录始终需用户的准确板型和安全确认。

回退前先保存当时最新账本/预算/出刊/请求去重记录，核对旧版状态兼容性。**不能直接倒灌升级前账本或旧指针覆盖新增记录**，也不恢复陈旧NVS/文件系统。回退不是已实测的万能救援按钮。

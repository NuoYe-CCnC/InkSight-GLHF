# test.13 本地候选说明（未发布）

这是一份开发候选说明，不是 GitHub Release 通知或新用户全链路通过证明。现有公开 test.9 资产不被修改；本轮没有更新生产 App、刷写真实设备或调用付费模型。

## 候选变更

- 在本机管理页增加“设备首次使用 / 固件”准备中心，列明主机、字体、工具、空间、已应用配置、Wi-Fi、云端和USB条件。
- 用户自行从官方取得静态 MiSans Regular/Bold 后图形导入；检查实际OTF/TTF、字重和必需字形，生成完整12份私有字库，成功后原子切换。失败保留旧字库，字体不进入App/源码ZIP。
- 使用App内置Python3.11建立私有工具环境。PlatformIO6.1.19及esptool附加依赖分别使用SHA256轮子锁，固定平台/框架/编译器/库；不修改系统Python，不sudo，不绕TLS，不借开发者缓存，未批准安装钩子拒绝。
- USB只读识别后确认绑定，初始无需抄写MAC。只读识别会短暂重启，不能当作写入授权或接线验证。
- 私有workspace构建，关联配置/源码/字体/工具指纹，核对ESP32-S3镜像与容量；过期构建不能刷写。
- 全空白板读取全部32MiB确认，未知或厂家预置板拒绝自动清空。兼容更新保护原活动应用/NVS/文件系统，动态写非活动槽，回读后仅改一个OTA扇区；首次启动保留已配Wi-Fi。
- 备份完成才提供五分钟一次性最终确认。正式Web更新和Web回退共用受控实现；回退只恢复旧启动扇区，不倒灌陈旧设置。新板部分写入或保护区异常时停止自动重启，不自动擦除。
- 将编译、写入回读、真实设备联网回执、人工实体屏确认分开。退出保护覆盖准备/构建/USB任务，中断记录不自动重放USB写入。
- 保留test.11成功发布快照预览、test.12重置预告、免root入口、设置迁移及静默菜单栏行为。实验辅助预告源的真实联网限制不因本轮准备中心实现而消失。

## 支持与许可

Apple Silicon / macOS26.5或更新，实际测试主机26.5.2；ESP32-S3 N32R16V（32MB Octal Flash/16MB PSRAM）与SSD1677黑白800×480。没有扩展Intel、Windows、其他板或屏。App仍为ad-hoc签名、未公证，不能保证下载后无系统安全提示。

项目软件GPL-3.0-only。MiSans不分发，工具链按需下载且保留各原许可；App的84个运行时组件、源码声明依赖和用户私有工具清单是不同范围，不能以旧SBOM代替新工具清单。

## 验收边界与暂缓项

自动化覆盖安全状态、字体解析、路径/上传/会话、失败原子保留、取消/退出、32MiB模拟Flash、双槽/保护区、确认重放和回退。合成字体/Flash不是官方字体导入或真实板卡证明。原生检查和签名校验也不替代浏览器操作或实体屏。

最终候选应分别记录：ZIP新解压、独立数据根正式界面操作、合法字体导入、从无缓存准备工具、配置与首次编译、原始PNG预览、只读USB预检、空白备用板首次写入、已有板升级/回退、联网与实体屏。未完成项必须保留为待验收；同一Mac隔离不是另一台全新电脑。没有备用空白板，不得清空现用设备充数。实际写入和公开发布仍各需当前明确授权。

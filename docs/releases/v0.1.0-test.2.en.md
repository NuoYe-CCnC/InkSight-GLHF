# InkSight-GLHF v0.1.0-test.2

Date: 2026-09-29
Status: public pre-release
Scope: gold-backend reliability and source update. No new firmware binary or device reflash is required for this backend update.

Host startup/wake and explicit device cold-start recovery now bypass the completed half-hour slot and scheduled night-mode gate. Existing firmware requests recovery only on genuine boot when its published quote is missing or older than 24 hours; minute wakes do not add calls. XAUS spot and USD-midnight intraday recovery share one lock and a minimum 30-second provider interval. HTTP 429 honors `Retry-After`; pending work is persisted, retries are bounded, and a queued cloud request is not removed before completion.

The backend keeps receipt (`fetched_at`), response (`updated_at`), and quote (`price_as_of`) times separate. It independently rejects old responses even if their `data_state` says `fresh`; old valid numbers remain visible as stale. A stale quote alone never proves market closure. USD/oz retains the Beijing-midnight tolerance/recovery baseline; CNY/g retains the first valid quote of the Beijing day, never an FX-derived or prior-day change. Old firmware can keep using `quote_time`.

Operators may tune `gold_refresh.response_max_age_seconds` (300 by default), `quote_max_age_seconds` (7200), and `cache_max_age_seconds` (2700). XAUS documents that consumers must check `updated_at` independently of `data_state.status`, while `price_as_of` identifies the quote time: [official API documentation](https://xaus.com/api/). Prices are reference data, not domestic retail prices or trading advice.

Back up private configuration, database, `shared/backend/state/`, and deployed source before upgrade. Pull this source release and restart the backend following the [installation and recovery guide](../INSTALLATION.en.md). The release does not overwrite private configuration or change the device-panel layout. To roll back, stop the backend and restore both the previous source and its matching state backup. There is no new-device-flash, cross-platform, or other-hardware acceptance claim. During network failure or provider throttling, a real cached quote may remain visible as stale.

The local offline suite passed 909 tests with two existing dependency warnings. The allowlisted source candidate passed a zero-finding privacy scan and clean-extraction file comparison; 50 relevant tests passed from the candidate. The local backend was restarted and reported fresh XAUS state; the existing WebDAV device file was published and its SHA-256 readback matched. This is not a device reflash or cross-platform installation test. No production credentials, real device MAC, MiSans font or derived glyphs, runtime cache/database, or firmware binary belongs in the source package. Report security issues [privately](https://github.com/NuoYe-CCnC/InkSight-GLHF/security/advisories/new).

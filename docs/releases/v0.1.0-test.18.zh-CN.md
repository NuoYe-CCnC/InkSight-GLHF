## 更新内容

1. **有边界的上下文。** 本人回复链核对作者、父子和时间；Day 编号系列可以继承明确的 Codex/reset 产品背景，有滚动期限和硬上限。其他事件的日期、套餐、次数不借用。支持转折后计划、修订、延期和取消，不用模型猜未明确的信息。
2. **午夜与待定时间。** 相对日期以原帖时间为准，PST/PDT/PT 区分；屏幕与菜单用北京时间。v2 分开表达精确时间、日期范围和时间待定，失效期限不再冒充预计到账时间。套餐未说明明确标注，不扩展成所有用户适用。
3. **查看预告原文。** 有效预告可在 Is 显示星号，提供与当前事件匹配的原文项；点击时再次核对身份、修订、链接和有效性，阻止旧事件误开。没有有效预告时不加星号；缺额度仍显示 `-`。
4. **辅助源独立恢复。** 主源确认原文，辅助源仅发现和佐证。暂时网络错误按失败后+10/+30分钟各一次有界重试，持久化限制并尊重夜间、429和访问规则；不会为辅助重试额外拉主源。无需 X Cookie 或令牌，不关闭 TLS。
5. **可读诊断。** 管理页区分 DNS、连接、TLS、超时、HTTP、解码与解析结果；显示来源查询时刻、候选原文、选择/未采用原因和北京时间。首次发现、识别、入快照、发布回读及设备证据分开。只读诊断按钮不触发第三方请求。
6. **介绍与演示图。** 中英文首页先给 App 下载、三步入门与硬件资料；四图来自正式renderer、隔离原生菜单组件和实际管理页。所有账户/报价是演示值，历史菜单显著标注非当前预告；准备页未执行 USB 写入。

实际额度、手动重置次数与到期、账本、新闻和切页规则不由预告推导。有效预告暂占已确认的右侧预留区域，失效后恢复用户的可选 API/点数设置。**实验开关默认 false；升级保留现有选择**。来源可缺失或变化，不保证提前通知、个人适用或个人到账。

## 升级与兼容性

普通功能的 App 更新不要求为匹配版本号重刷。**完整启用 v2 预告需要 App 与支持 `announcement_schema_max >= 2` 的兼容固件同时具备**；仅识别 v1 的旧固件不等于 v2 可用。无有效预告时不显示“预计”或星号是正常行为。

先正常退出旧 App，私密备份此刻最新配置、数据、账本和偏好，在原路径替换完整 App，并核对唯一发布者。设备需更新时走[准备中心](../DEVICE_FIRST_USE.zh-CN.md)和[已有设备 update](../UPGRADE.zh-CN.md)：核对身份/分区，完整备份，只写非活动槽，完整回读、保护区域核对后切换启动项。保留有效 NVS/Wi-Fi/文件系统，不整片擦除，不用编译默认值覆盖现用网络。回退前保留升级后新增记录，不倒灌旧账本。

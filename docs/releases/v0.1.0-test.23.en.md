# v0.1.0-test.23 · Menu quota, Chinese briefs and subscription renewal

Cumulative public prerelease since test.19. Download the [Apple Silicon app](https://github.com/NuoYe-CCnC/InkSight-GLHF/releases/download/v0.1.0-test.23/InkSight-macOS-arm64.zip) or [source archive](https://github.com/NuoYe-CCnC/InkSight-GLHF/releases/download/v0.1.0-test.23/InkSight-Source.zip).

- Is retains the last verified quota across brief failures for the same account and seven-day window. The menu shows the confirmation time. The sample expires at the earliest applicable boundary, within 30 minutes.
- Chinese technology briefs can retain product names. English narrative is revised and claims are checked against source excerpts. Each issue allows up to three model calls including initial generation. If no validated Chinese fallback is available, the previous issue remains visible with its original status and date of issue marked as awaiting an update.
- App Store subscribers can opt in to reading the Plus renewal date through macOS Accessibility. The usage page distinguishes renewal from expiry. Is provides manual checks for subscriptions and experimental reset notices. Optional daily notice checks run at 06:00 Beijing time with catch-up. Optional model analysis requires separate opt-in.

Requires Apple Silicon and macOS 26.5+. The app is ad-hoc signed and has no Apple notarization. Verify the checksum, back up settings and ledgers, quit the old app and replace the entire bundle. Check Accessibility permission after upgrading if you use subscription reading. Menu and brief changes require only the Mac update. Devices already supporting renewal labels can keep their firmware. Older boards need a locally built compatible firmware for the new membership line. Obtain MiSans separately.

Local delivery recorded 806 passing regression tests and 57 native menu checks. An existing device received and displayed the renewal field. A second Mac, blank-board installation and long-running outage behavior have not received equivalent acceptance. [Upgrade guide](../UPGRADE.zh-CN.md) · [Checksums](../DOWNLOAD.zh-CN.md)

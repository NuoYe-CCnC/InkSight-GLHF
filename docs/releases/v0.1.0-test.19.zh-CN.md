# v0.1.0-test.19：关注页底栏预告

2026-10-29。**公开测试版（pre-release），不是稳定版。**

## 本版变化

- 关注页仅右底栏在有效预告期间显示`Codex 预计…`，无效/取消/到期恢复INKSIGHT。左侧状态和更新时间保留，MiSans Regular21同基线，正文/金价/基本用量不压缩。
- 两页与Is沿用同一v2 selected_event，区分截止“前”、准确时点和时间待定；单日/跨日范围按北京时间。用量页现有两行保持。
- 只更新当前页，不因预告强制切页或延长AI活动。可见文本变化进入关注页视觉指纹；查询时间、辅助证据或文字相同的修订不触发重画。
- 设备缓存payload ID不变也能在下一次既有显示/唤醒机会撤下到期预告；断网保留未过期已核验计划，未知时钟不猜时间。没有增加抓取或唤醒。深睡期间旧字可能保留至下次正常唤醒。

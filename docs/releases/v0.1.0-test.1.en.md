# InkSight-GLHF v0.1.0-test.1

Release date: 2026-09-20  
Status: public test release (pre-release)  
Repository: <https://github.com/NuoYe-CCnC/InkSight-GLHF>

This is the first public test release of InkSight-GLHF, targeting ESP32-S3 N32R16V and the Waveshare 4.26-inch SSD1677 800×480 monochrome display. It includes the local backend, browser console, `AI Usage` and `Today` panels, example configuration, build tools, and firmware source.

## Highlights

- Local root administration, draft/validate/apply configuration, and two-page previews; there is no default username or password.
- Codex window information, DeepSeek balance and project token usage, plus optional OpenAI organization UTC-month costs.
- XAUS international spot-gold conversion with a Beijing-day first-valid-quote baseline.
- All remote news sources disabled on fresh installs; four GPL-3.0-only local messages when no key or enabled source is available.
- Local MiSans validation, import, and glyph generation tools; no fonts, derived glyph data, previews, or firmware binaries are distributed.
- Build and controlled flashing source for the single verified target, `epd_426_ssd1677_s3_n32r16`.
- GPL-3.0-only top-level license, third-party notices, SBOM, bilingual installation docs, security policy, and issue templates.

## Validation boundary

- Verified baseline: macOS ARM64, Python 3.9, ESP32-S3-DevKitC-1-N32R16V, and Waveshare 4.26-inch SSD1677 800×480.
- During release preparation, 873 automated tests passed with two existing dependency warnings; 56 documentation/release tests passed; 56 bundled tests passed from a fresh extraction of the candidate ZIP.
- The final release archive is rebuilt with an allowlist, privacy scan, unsafe-path checks, fresh-extract file comparison, and deterministic digest checks.
- At the publisher's request, this release skips a remote “download from public GitHub → install → run” acceptance pass. Page availability and local automated tests are not cross-platform installation validation.
- No device was reflashed, no production service was restarted, and no live paid API was called for this release.

## Known limitations

- This is a test release. Windows, Linux, Intel Mac, other boards, and other displays do not have equivalent qualification.
- Scheduled publication cannot be guaranteed while macOS sleeps; a device wake does not imply that the backend host is awake.
- A one-week lifetime from a 2000 mAh battery has not been measured and is not claimed.
- The four local messages repeat. Deployers must review licensing, attribution, links, privacy, and service terms before enabling each remote news source.
- `API monthly spend` is the OpenAI Organization Costs API result for an organization and UTC calendar month. It is not an API balance or total personal Codex spend.

## Installation and verification

Read the [installation, configuration, font, build, flash, upgrade, and recovery guide](../INSTALLATION.en.md) first. Release assets include `InkSight-Source.zip`, `InkSight-Source.zip.sha256`, and a machine-readable receipt. Verify SHA-256 before use. Back up private settings, the database, and runtime state before upgrading, then inspect legacy migration with `migrate --dry-run`.

Report security issues through the repository's [private vulnerability reporting form](https://github.com/NuoYe-CCnC/InkSight-GLHF/security/advisories/new). Do not post secrets, databases, real MAC addresses, Wi-Fi credentials, or cloud credentials in public issues.

# InkSight-GLHF v0.1.0-test.1

发布日期：2026-09-20  
状态：公开测试版（pre-release）  
仓库：<https://github.com/NuoYe-CCnC/InkSight-GLHF>

这是 InkSight-GLHF 的首个公开测试版，面向 ESP32-S3 N32R16V 与微雪 4.26 英寸 SSD1677 800×480 黑白墨水屏。它包含本机后端、网页管理端、`AI 用量`与`今日关注`两套面板、示例配置、构建工具和固件源码。

## 主要内容

- 本机 root 管理、配置草稿/校验/确认应用和双页预览；项目没有默认用户名或默认密码。
- Codex 窗口信息、DeepSeek 余额与本项目 Token、可选的 OpenAI 组织 UTC 月消费。
- XAUS 国际现货金价换算，以及北京时间当日首条有效报价基线。
- 新安装默认关闭全部远程新闻源；无 Key/无已启用来源时使用四条 GPL-3.0-only 本地寄语。
- MiSans 本地校验、导入和字库生成工具；仓库与 Release 不分发字体、派生字库、预览图或固件二进制。
- 唯一已验证硬件目标 `epd_426_ssd1677_s3_n32r16` 的构建和受控刷写源码。
- GPL-3.0-only 顶层许可、第三方通知、SBOM、中英文安装文档、安全政策和 Issue 模板。

## 验证边界

- 已验证基线：macOS ARM64、Python 3.9、ESP32-S3-DevKitC-1-N32R16V、微雪 4.26 英寸 SSD1677 800×480。
- 发布准备阶段全量自动回归 873 项通过、2 条既有依赖警告；文档/发布专项 56 项通过；候选 ZIP 全新解压后的随包专项 56 项通过。
- 最终发布包会重新执行允许列表构建、隐私扫描、危险路径检查、逐文件解压比对和确定性摘要检查。
- 按发布者要求，本次跳过“从公开 GitHub 下载→安装→运行”的远程端到端验收；不要把页面可访问或本地自动测试理解为跨平台安装验收。
- 本次没有重新烧录设备、重启生产服务或调用真实付费 API。

## 已知限制

- 这是测试版，不承诺 Windows、Linux、Intel Mac、其他开发板或其他屏幕的同等级支持。
- macOS 睡眠期间不能保证按时出刊；设备唤醒不代表后端主机同时在线。
- 2000 mAh 一周续航没有规范实测，不作为能力声明。
- 四条本地寄语会重复；远程新闻源启用前由部署者逐源审查许可、归因、链接、隐私和服务条款。
- `API 本月消费` 是 OpenAI Organization Costs API 返回的组织 UTC 自然月消费，不是 API 余额，也不是个人 Codex 全部开销。

## 安装与校验

请先阅读[安装、配置、字体、构建、刷写、升级与恢复指南](../INSTALLATION.zh-CN.md)。Release 附件提供 `InkSight-Source.zip`、`InkSight-Source.zip.sha256` 和机器可读收据；下载后先核对 SHA-256。升级前备份私有配置、数据库与运行状态，并先运行 `migrate --dry-run`。

安全问题请使用仓库的[私密漏洞报告入口](https://github.com/NuoYe-CCnC/InkSight-GLHF/security/advisories/new)，不要把密钥、数据库、真实 MAC、Wi-Fi 或云端凭据发到公开 Issue。

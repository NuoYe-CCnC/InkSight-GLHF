# v0.1.0-test.23 · 菜单栏额度、中文简报与订阅续期

这是自 test.19 以来的累计公开测试版。下载 [Apple Silicon 版 Mac App](https://github.com/NuoYe-CCnC/InkSight-GLHF/releases/download/v0.1.0-test.23/InkSight-macOS-arm64.zip) 或 [开发者源码](https://github.com/NuoYe-CCnC/InkSight-GLHF/releases/download/v0.1.0-test.23/InkSight-Source.zip)。

- **菜单栏额度**。同一账户、同一七日窗口短暂断连时，Is 保留最近确认的剩余百分比，菜单内显示确认时间。过期、换号或窗口重置后清除旧值。有效期限最长 30 分钟，0% 也会正常显示。
- **中文科技简报**。正文可保留 OceanBase 等产品专名，英文叙述单独修订，关键事实与来源片段核对。每期最多调用 DeepSeek 三次，含首次生成。预算用完可采用通过校验的中文原文，否则保留上期并标明未更新。
- **Apple 订阅**。App Store 渠道用户可在设置中开启订阅读取，向正式安装的 InkSight 授予 macOS 辅助功能权限。Is 提供手动查询入口，自动查询集中在续期日前后。用量页区分“续期”和“有效至”，保留 Apple 提供的日期精度。
- **实验性 Codex 重置预告**。可开启每日北京时间 06:00 查询，错过可补查，也可从 Is 手动查询。可选 DeepSeek 分析需要单独开启，判定结合原文和上下文。预告以公开来源为依据，实际到账以账户为准。

## 安装与升级

Apple Silicon，macOS 26.5 或更高版本。App 内含 Python，采用 ad-hoc 签名，尚未获 Apple 公证。先核对同版 SHA-256，再退出旧 App、备份现有配置与账本，在原位置替换完整 App。使用 Apple 读取的用户升级后请核对辅助功能权限。

菜单栏与简报改动仅需更新 Mac App。已有设备若能正确区分续期与有效期，可继续使用当前固件。从 test.19 或更早固件升级且需要新会员行时，请按[已有设备升级说明](../UPGRADE.zh-CN.md)本地构建、备份并升级。MiSans 由使用者从官方获取后本地导入。新安装默认关闭远程新闻源、订阅读取和实验预告。

## 验证范围

本机交付记录有 806 项回归和 57 项原生菜单检查通过。已有设备验证了续期字段的接收与实屏显示。额度超时通过故障回放验证，真实长期断连、另一台 Mac 首次启动及空白板首次烧录仍缺少同等验收。

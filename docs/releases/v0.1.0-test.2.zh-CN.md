# InkSight-GLHF v0.1.0-test.2

发布日期：2026-09-29
状态：公开测试版（pre-release）
范围：金价后端可靠性与开放源码更新；**没有新固件二进制，也无需因本次后端更新刷写设备**。

## 本次改动

- 主机启动、唤醒与设备真实冷启动请求不再被“本半小时定时任务已完成”或夜间定时开关吞掉。设备当前固件仍只在真正冷启动且本地已发布报价缺失或超过 24 小时时发起补拉；分钟级唤醒不增加请求。
- 所有 XAUS spot 与北京时间零点 USD 基线的 intraday 补查共用请求锁及不低于 30 秒的间隔。429 遵从 `Retry-After`，失败不会立即连发。事件结果区分已完成、待重试和到达上限后的终止；待重试保存在本地状态，云端设备请求文件在完成前保留。
- 区分本机抓取时间 `fetched_at`、XAUS 响应时间 `updated_at` 与真正报价时间 `price_as_of`。即便供应商 JSON 写着 `fresh`，超龄响应、超龄报价与本机超龄缓存也会标记为旧数据，保留真实数值但不冒充新报价。过时不等于休市：除非供应商明确给出可信休市字段，否则休市状态为未知。
- USD/盎司保留北京时间零点附近容差取点及受限日内补查；CNY/克保留当日首条有效报价作为独立基线，不用汇率推造人民币涨跌，也不把上一日变化带到次日。
- 可配置 `gold_refresh.response_max_age_seconds`（默认 300）、`quote_max_age_seconds`（默认 7200）和 `cache_max_age_seconds`（默认 2700）。设备旧版字段 `quote_time` 继续与实际报价时间一致，保持兼容。

XAUS 官方说明：`data_state.status` 只描述响应生成时的状态；使用方仍应独立检查 `updated_at`，`price_as_of` 才是实际报价时间。请阅读 [XAUS API 文档](https://xaus.com/api/)；金价仅供参考，不是国内零售金价或交易建议。

## 升级与回退

升级前备份本机私密配置、`shared/backend/state/`、数据库及当前部署源码；**不要把备份提交到 GitHub**。拉取本测试版源码并按[安装与升级指南](../INSTALLATION.zh-CN.md)重启后端即可；本版不迁移/覆盖私密配置，不改变两页设备布局。发布端可继续使用现有固件。若回退，先停后端、恢复对应旧版源码和升级前状态，再启动，不要用旧版代码解释新版状态文件。

新逻辑优先保证报价时间真实、避免无界重试。断网或供应商限制期间可能显示旧报价及旧数据状态；主机睡眠时无法保证按点抓取。没有设备重刷、其他操作系统和硬件的本版验收声明。

## 验证

本地离线全量测试 **909 项通过**、2 条既有依赖警告；源码候选经允许列表、隐私扫描（0 项发现）及全新解压逐文件校验，候选包内相关专项 **50 项通过**。本机后端已受控重启并读到新鲜 XAUS 状态；现有坚果云设备文件已发布且回读 SHA-256 一致。这些检查不等于设备实机重刷或跨平台安装验收。源码包不含生产密钥、账户、真实 MAC、MiSans 字体或派生字库、生产缓存、数据库及固件二进制。

安全问题请走[私密漏洞报告](https://github.com/NuoYe-CCnC/InkSight-GLHF/security/advisories/new)，不要把凭据或设备信息贴到公开 Issue。

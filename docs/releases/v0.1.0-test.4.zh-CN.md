# InkSight-GLHF v0.1.0-test.4

发布日期：2026-09-30
状态：公开测试版（pre-release）
范围：Apple Silicon Mac 应用与同版源码；**不含新固件二进制，不要求为本次主机更新重新烧录设备**。

## 本次修复

- Mac App 的发布循环现在先读取本机 Codex CLI 的订阅额度，再组成云端页面。需要本机已安装并登录 Codex CLI；读取额度不会调用模型或消耗手动重置机会。找不到 CLI 或官方返回信息不完整时，界面保留未知/陈旧状态，不编造到期日。
- 手动重置机会的到期列表与 7 日窗口分开校验。只有同账户、同次数的短暂缺失才允许沿用最长 20 分钟的已核实列表；次数变更、账户切换、明确撤销、无效日期、乱序旧样本都不能继续显示旧到期日。同一秒内先收到不完整样本、后收到核实详情时可以补全。
- 源码加入针对受支持 ESP32-S3 32 MB 设备的受控 OTA 更新/回退准备：操作前校验设备、分区和私有备份，刷写只在明确确认后发生，回退只恢复原 OTA 启动项，不覆盖设备 NVS。**这套新回退操作只做了离线模拟和只读预检，尚未获授权做实机写入或回退；请勿把它当作已验收的救援功能。**较早刷写任务没有完整双分区备份时不能使用新回退按钮。

## 验证与限制

本仓库后端测试 **155 项通过**；源码候选通过允许列表、隐私扫描和全新解压复核。Mac ARM64 App 在 Apple Silicon、macOS 26.5.2 上通过隔离首次启动、单实例、退出/端口释放、签名与解压校验。App 仍仅为 **ad-hoc 签名，未获 Apple Developer ID 签名或公证**；请按[下载与校验说明](../DOWNLOAD.zh-CN.md)核验，不要关闭系统安全功能。

在同一台主机与已授权的坚果云/设备上，旧发布者暂停期间，新 App 的隔离数据目录完成了云端测试、真实内容上传与回读。操作者实际看到设备刷新后的 AI 用量页：手动重置 2 次及到期时间正常；随后看到今日关注页显示完整的今日 Token 数字 `5967` 和 08:56 出刊的早报，并确认观察期间未出现反复来回切页或文字重叠。候选端停止后，旧服务恢复并重新发布。该短时测试不等于第二台全新 Mac、长期休眠恢复或新固件刷写验收。

为避免测试调用付费服务，候选端只导入了显示所需的真实状态快照和云端凭据，**没有导入付费 API 密钥或共用生产 SQLite**。因此测试中余额快照超过设备的 3 分钟新鲜度阈值后，页脚如实显示“部分数据陈旧”；这不表示 Token 或早报数字为虚构值。实际长期运行仍需用户自行配置授权来源与密钥，并理解可能的费用。无模型付费调用、固件写入或手动重置机会消耗属于本次验收内容。

应用包与源码 ZIP 是不同资产；源码包不含生产密钥、真实设备标识、私有配置/数据库、MiSans 原字体或派生字库。固件开发者请先读[实验性更新与回退说明](../FIRMWARE_UPDATE_ROLLBACK.zh-CN.md)和[支持矩阵](../SUPPORT_MATRIX.md)。安全问题请走[私密漏洞报告](https://github.com/NuoYe-CCnC/InkSight-GLHF/security/advisories/new)。

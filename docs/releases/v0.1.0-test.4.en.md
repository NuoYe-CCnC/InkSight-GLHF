# InkSight-GLHF v0.1.0-test.4

Date: 2026-09-30
Status: public pre-release
Scope: Apple Silicon Mac app and matching source archive. **No new firmware binary or required device reflash.**

The desktop publisher now reads the local Codex CLI subscription quota before composing the cloud payload. The CLI must be installed and signed in. This read does not invoke a model or consume a manual reset opportunity. Missing or incomplete upstream details remain unknown or stale rather than becoming invented expiry dates.

Banked reset expiries are verified separately from the seven-day usage window. A verified list may be reused for at most 20 minutes only when the account and opportunity count are unchanged and a subsequent detail read is missing. Count/account changes, explicit revocation, invalid dates and out-of-order samples cannot retain old expiries. A verified detail arriving in the same second may repair an earlier partial sample.

The source also adds guarded OTA update/rollback preparation for the supported 32 MB ESP32-S3 target: device/partition/backup checks, explicit write confirmation, and rollback of the original OTA selection without restoring old NVS. **The new rollback path has only offline simulation and read-only device preflight. No physical write or rollback was authorized or performed; do not treat it as a qualified rescue feature.** Older flashes without a complete two-app backup cannot use the new rollback button.

All **155 backend tests passed**. The source candidate passed allowlist, privacy and fresh-extract checks. The arm64 app passed isolated first launch, single-instance, exit/port-release, signature and ZIP extraction checks on Apple Silicon macOS 26.5.2. It remains **ad-hoc signed, not Developer ID signed or Apple notarized**. Verify the asset and checksum before choosing to run it; do not disable macOS security.

In a bounded handoff on the same host, authorized WebDAV account and device, the old publisher was stopped while the candidate used an isolated data directory to probe, publish and read back real content. The operator saw the device refresh its AI Usage page with two manual-reset opportunities and expiry dates, then the Today page with the full token count `5967` and the 08:56 morning issue, and reported no repeated page switching or text overlap during observation. The candidate stopped and the old service and cloud publication were restored. This does not qualify a second clean Mac, long sleep recovery or a new physical firmware flash.

To avoid paid-service calls during acceptance, the candidate received only real display snapshots and WebDAV credentials—not paid API keys or the production SQLite database. Its balance snapshot therefore became older than the device's three-minute freshness threshold and was truthfully marked partially stale. Normal operation still requires the operator to configure authorized sources and consider their costs. No paid model call, firmware write or manual reset opportunity was consumed in this acceptance.

The Mac app and source ZIP are separate assets. Neither distributes production credentials, device IDs, private state/databases, MiSans fonts or derived glyphs.

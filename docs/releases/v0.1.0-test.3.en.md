# InkSight-GLHF v0.1.0-test.3

Date: 2026-09-29
Status: public pre-release
Scope: first standalone Apple Silicon Mac app. No new firmware binary or required device reflash.

The app bundles CPython 3.11.15, the backend and hash-locked dependencies. It was isolated-tested on Apple Silicon with macOS 26.5.2, including a read-only app in a path with Chinese characters and spaces, fresh user data, local first-root creation, loopback health, and process cleanup. It needs no separately installed Python, Homebrew or repository checkout at runtime. Other OS versions and hardware were not equivalently qualified.

The repository's 139 backend/release tests passed. `APP_COMPONENTS.json` inventories the bundled interpreter and 84 Python distributions; the older `SBOM.json` remains a Python 3.9 source-install audit snapshot, not an exact app bill of materials.

Its control window manages the loopback backend, port, first-use status, collection-document status, optional scheduled network collection, explicit WebDAV probe, and cloud publication. Fresh installs leave network collection off and do not implicitly invoke paid models. User data lives under the current user's Application Support directory. Versioned runtime directories preserve the previous version; importing an existing source deployment requires explicit preview, backup and confirmation. The old deployment is not automatically read or modified.

**This test app is ad-hoc signed, not Developer ID signed or Apple notarized.** macOS may block its first launch after download. Check the asset's SHA-256 and its origin first; do not globally disable system security. If you choose to test it, follow [Apple's own guidance](https://support.apple.com/en-gb/102445) for a blocked app. A normal, warning-free installation requires a future Developer ID signed and notarized build. See the [Mac app guide](../APP_DESKTOP.zh-CN.md) and [download checks](../DOWNLOAD.zh-CN.md).

This release does not claim a second clean-Mac test, long-running sleep recovery, a real WebDAV account test, or a new physical display acceptance run. Host health is not collection freshness or proof of display delivery. The separate `InkSight-Source.zip` is privacy-scanned source, not an installer. No production credentials, personal device identifiers, MiSans font or derived glyph assets, production cache or database are distributed. See the [upgrade and rollback guide](../UPGRADE.zh-CN.md); report sensitive issues [privately](https://github.com/NuoYe-CCnC/InkSight-GLHF/security/advisories/new).

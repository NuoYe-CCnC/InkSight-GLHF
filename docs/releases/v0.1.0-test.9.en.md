## Changes

- Quiet Is menu-bar startup, approved original B2 icon, window close hides rather than quits. Reopen through the menu; safe quit waits for admitted work and protects firmware writes. Single-instance, recovery, pause/resume and fallback-window behavior are tested. Existing login items are retained at the same path; fresh installs do not enable them automatically.
- Actual Is → “打开配置” opens a protected local browser session without root credentials. Old account records and business data are retained. One-use tickets, per-open entry paths, content-versioned assets, short sessions and loopback/Host/Origin/CSRF protections remain in place. Standalone source deployments still use administrator login.
- The icon's adjacent integer shows remaining Codex 7D quota from the existing local cache. Zero is valid; missing, failed, invalid, wrong-account or expired samples show ASCII `-`. The app reads a protected local endpoint every 15 seconds; no extra upstream collector or probing frequency is added, and reads/failures never extend freshness.
- News issue state travels with its body, distinguishing waiting/generating/unavailable/yesterday without incorrectly labeling a retained midday edition as “morning pending.” Temporary device messages expire without deleting persistent request deduplication.
- Unified gold calculations use one XAUS response: USD spot P, USD/CNY R and G=31.1034768; CNY price=P×R/G, USD change=P−B, CNY change=(P−B)×R/G. Beijing-day baseline B is exact midnight when available, otherwise the earliest valid post-midnight history point available, fixed for that day. Invalid FX cannot mix new and old values; old complete snapshots are explicitly stale. Source requests have a 60-second floor and bounded history budget/backoff.

Converted international gold is not a domestic gold quote; its change does not include historical FX movement. **Old firmware cannot fully show the new news states/gold baseline labels.** Matching firmware source is included, but no ready-to-flash image and no automatic device flash. See [gold semantics](../GOLD_UNIFIED.zh-CN.md), [menu/session boundaries](../MENU_BAR.zh-CN.md) and [Chinese full notes](v0.1.0-test.9.zh-CN.md).

## Verified and not verified

- 362 backend tests and 28 native pure checks passed with isolated data and no paid generation. Isolated app lifecycle checks cover startup/hide/reopen, duplicates, backend recovery, critical in-flight exit protection, pause/resume, graceful quit and menu failure fallback.
- Existing Mac safely upgraded with managed private data matched byte-for-byte, database integrity and preferences preserved, existing login item retained. One app/backend/publishing loop; loopback-only service. Cloud upload/readback matched the local publication record, not a hardware receipt.
- User confirmed the **real installed Is configuration entry no longer asks for root**, and the menu-bar percentage is correct. Cache tests do not prove the sole cause of the earlier incident.
- **Still unverified:** new gold presentation on the physical display; complete new-user remote download→install→run; a second clean Mac, Intel/Windows/Linux, long-running/sleep recovery, and physical firmware rollback. No device was flashed for this release. Preview, prior screen checks and cloud readback are not substituted for these acceptance items.

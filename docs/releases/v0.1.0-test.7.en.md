# InkSight-GLHF v0.1.0-test.7 (release candidate)

Combines the unpublished news-issue status fixes and unified gold calculation.
test.6 was a local transition build; published test.5 assets remain unchanged.
This document does not mean a GitHub release has been published.

One XAUS response supplies P (USD/troy oz) and R (USD→CNY). With G=31.1034768,
CNY/g=P×R/G, USD change=P−B, converted CNY/g change=(P−B)×R/G.
Keep raw precision until display; show two decimals and suppress negative zero.
Do not use xau.price as the authoritative converted price or freeze a CNY first sample.

B is an exact Beijing-day midnight USD quote, otherwise the earliest available
valid same-day historical sample after midnight, never a previous-day neighbor.
Persist the immutable daily reference and its true source timestamp with schema 2.
The screen labels the actual reference and conversion; unknown changes remain unknown.
The earliest sample may be seconds after midnight, displayed to minute resolution,
without pretending to be an exact-midnight sample or the market's first trade.

This is international gold converted to CNY, not an SGE domestic quote. The change
excludes historical FX movement. One response does not imply simultaneous upstream
source timestamps; the independent FX timestamp remains unknown. Invalid/stale FX
cannot produce a fresh CNY result; retain an entire previous response snapshot,
with its original operands/times and an explicit stale label, or show unknown.

Keep scheduled/start/wake behavior with a shared minimum 60-second provider budget.
Legacy 30-second settings still load but cannot bypass the 60-second runtime floor.
History recovery has persistent cooldown/daily limits and respects Retry-After.
News body, issue and status are coherent, including custom issues, publication before
ledger commit, generating/failure states and day rollover. A current noon issue
must not be mislabeled as waiting for the morning issue.

263 isolated tests and six font/layout cases passed locally. App configuration and
paid/completed-issue records were preserved. A fresh 32MB device backup was verified;
only the inactive application slot and alternate OTADATA sector were written.
NVS was byte-identical before boot; 11 user settings matched after boot. The prior
application slot remains. No autostart installation, filesystem, partition-table,
bootloader or configuration partition write was performed.

New gold physical-screen acceptance remains an independent release gate; previews
and cloud calculations cannot replace it. This candidate does not claim that gate
is complete. Long-term operation is not yet certified. App is an Apple Silicon/macOS
26 test build, ad-hoc signed, not Apple notarized. No private config, keys, MiSans
fonts or font-containing firmware binary is distributed. Build firmware locally
with lawfully supplied fonts. Preserve the latest paid/de-duplication records on
upgrade and rollback, and use the retained application slot rather than full-chip
erase. See [gold contract](../GOLD_UNIFIED.zh-CN.md),
[news status](../NEWS_ISSUE_STATUS.zh-CN.md) and [hardware/source notes](../../README.en.md).

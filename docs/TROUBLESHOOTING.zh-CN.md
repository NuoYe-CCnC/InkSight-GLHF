# 常见问题与安全排查

[文档目录](README.md) · [首次使用](FIRST_USE.zh-CN.md) · [支持矩阵](SUPPORT_MATRIX.md)

| 表现 | 先检查什么 |
|---|---|
| 找不到 `python3.9` | 看 `python3 --version` 是否确实为 3.9.x；是则在创建虚拟环境的命令中改用 `python3`。不能把其他版本当作已验证基线。 |
| 校验文件不匹配 | ZIP 和 `.sha256` 必须来自同一 Release；失败即停止，不运行/刷写。 |
| `init` 拒绝 | 可能已有旧 `manual_settings.json` 或只存在一份新配置；先备份、执行 `migrate --dry-run`，不要删除旧配置强行重来。 |
| 打不开管理端 | 确认前台脚本仍在运行、终端无启动错误、浏览器访问同一台 Mac 的 `127.0.0.1:8080`，再检查 `/api/health`；端口被占用时可设 `PORT`。 |
| App 提示 root 或会话失效 | test.9 App 应从 Is →“打开配置”重新进入，不使用旧书签或旧登录页面；无需建 root、清数据库或清全局缓存。仍出现时核对运行版本、端口及是否误用了源码服务。 |
| 源码部署首次 root 创建入口不可用 | 必须在后端所在 Mac 的本机回环地址打开；没有默认密码。忘记已有管理员密码时看[恢复工具](INSTALLATION.zh-CN.md#8-运行休眠与恢复)。 |
| 页面只显示本地寄语或 `--` | 新安装远程新闻默认关闭；未知、未配置、数据过时与数值 0 不同。检查是否主动启用来源、提供对应密钥，以及管理端数据时间戳。 |
| 设备没有新画面 | 后端健康、云端成功、设备联网、设备实际拉取、固件版本是不同环节。按[主机发布](HOST_RUNTIME.zh-CN.md)与[安装/接线](INSTALLATION.zh-CN.md)逐环检查。 |
| 固件构建缺字库 | MiSans 原字体与派生字库不能随发行包提供；按[官方来源与本地导入](INSTALLATION.zh-CN.md#4-misans-本地导入)操作。 |
| 构建/刷写目标不对 | 只使用已验证 `epd_426_ssd1677_s3_n32r16`；默认 PlatformIO 环境是历史项，不能代表当前硬件。拒绝刷写时核对板型、32 MB Flash、分区与连接，勿绕过检查。 |
| Mac 睡眠后漏刊 | 后端和发布器在主机睡眠期间不能运行；设备自己的唤醒不等于主机唤醒。保持主机唤醒或自行审查常在线部署。 |
| 金价看起来像汇率或过时 | 金价应是 XAUS 国际现货换算，不是汇率本身；核对报价时间、抓取时间与陈旧状态。不要把后端健康 `ok` 当作报价新鲜保证。 |

公开 Issue 只附可脱敏重现步骤、软件版本、支持硬件型号和错误分类；不要贴 `.env`、私密配置、API Key、WebDAV 地址/密码、真实 MAC、余额、生产数据库或未脱敏照片。安全问题请按[安全政策](../SECURITY.md)私密报告。

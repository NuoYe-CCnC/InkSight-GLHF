# 候选包、测试与待办

## 候选包规则

候选目录由显式允许列表生成，不复制整个工作区。排除实际配置、秘密、数据库、日志、状态、备份、缓存、设备标识、用户绝对路径、运行上传、原始字体、生成字库、固件 BIN 和历史预览。`member_config.json` 在候选中固定生成为空对象，绝不复制当前个人套餐资料。

生成命令：

```bash
shared/backend/.venv/bin/python shared/tools/release/build_candidate.py
```

输出：`release-candidate/InkSight-Source/`，包括逐文件 SHA-256 的 `SOURCE-MANIFEST.json` 与不打印秘密内容的 `PRIVACY-SCAN.json`。候选目录带工具标记后才允许安全重建；不会覆盖任意现有目录。

当前压缩包为 `release-candidate/InkSight-Source.zip`，校验值写在同目录的 `InkSight-Source.zip.sha256`。该值在候选内容再次变化后会重新生成，不在候选包内部硬编码。

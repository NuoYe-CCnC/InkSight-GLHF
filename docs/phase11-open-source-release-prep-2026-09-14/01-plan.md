# 第二阶段：开源安装与发行候选包准备计划

日期：2026-09-14

## 目标

在不公开 GitHub、不复制用户隐私、不改变现有设备字体和屏幕布局的前提下，形成一个基于明确 allowlist 的独立发行候选目录，并完成当前机器可执行的安装、配置、字体导入、构建与安全检查。凡需最终许可证选择、空白板实烧、真实睡眠/断网或外部发布的部分，记录为第三阶段前阻塞项。

## 实施顺序

1. 只读盘点当前有效公开配置、运行代码、字体及派生产物、依赖和既有打包入口。
2. 建立脱敏的“当前规则 → 开源首次默认”对照表，个人数据、密钥、设备和缓存不继承。
3. 将已确认的非敏感运行规则固化为仅首次初始化使用的默认值，补充升级不覆盖测试。
4. 增加 MiSans 本机私有导入与派生字库生成流程：只接受用户本机选择的官方字体文件，检查格式、大小、字形与版本；任何字体文件、派生头文件、位图、预览或内嵌字体固件均不进入候选包。
5. 核对管理网页中配置项与后台校验/运行逻辑一致，只补必要的字体导入状态和中文阻断提示，不改变界面设计。
6. 建立发行 allowlist、离线隐私/许可扫描和清单生成脚本；在独立目录生成候选包，不复制整个工作区。
7. 盘点第三方依赖和许可证，生成 NOTICE、许可证缺口与顶层许可证候选建议，不擅自选定最终许可证。
8. 在隔离目录验证无密钥初始化、首位 root、配置草稿、无 Key 降级、字体缺失阻断、依赖预检和可离线完成的构建步骤。
9. 运行专项与全量回归，记录代码、网页、部署、烧录、实机和待验收状态。

## 安全与回退

- 本阶段不读取或输出任何密钥值，不复制真实配置、数据库、日志、缓存、备份、管理员或设备标识。
- 不调用付费模型、不刷新真实 OpenAI 费用、不充值、不使用重置额度。
- 不删除原文件；候选包生成到新目录。任何扫描结果只报告规则和脱敏文件名。
- 不 erase-all、不用现有设备冒充空白板、不在纯打包阶段重复烧录。
- 源码修改前建立私密备份；候选包可直接删除并重新生成，不反向覆盖工作区。

## 预期交付

- 独立发行候选目录、SHA-256 清单、allowlist 与脱敏扫描报告。
- 快速开始、配置默认值、API 申请、MiSans 官方下载与本机生成、支持矩阵、构建烧录升级恢复、中文排错、第三方许可与待决项。
- 自动测试记录和第三阶段人工验收清单。

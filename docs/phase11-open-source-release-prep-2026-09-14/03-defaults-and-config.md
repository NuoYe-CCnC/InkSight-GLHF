# 默认值、配置与生效边界

## 首装默认值来源

`shared/config/inksight_config.example.json` 与代码中的 `DEFAULT_CONFIG` 应完全一致。它采用当前实机运行规则中不敏感的部分：北京时间、工作日/休息日三种运行模式、08:55/12:55/16:55 出刊、工作日 22:00 与休息日 20:00 截止、每期最多 5 次调用、金价最短请求间隔 30 秒、OpenAI 月费用每 60 分钟刷新。

首装绝不继承：Wi-Fi、任何 API Key、坚果云账户、设备 MAC/ID、管理员账户、个人套餐到期日、余额、Token 初始值、历史用量、新闻缓存、数据库、日志和备份。

## 配置文件

- `inksight_config.json`：普通设置，可从示例初始化。
- `inksight_secrets.json`：Wi-Fi、API Key 和云端凭据，必须为 `0600`。
- `backend/state/`：缓存、账本、任务与设备状态，不是用户配置。
- `.env`：兼容服务的环境变量，不提交。

管理端覆盖现有运行字段：工作日/休息日时段、手动工作日/休息日、活跃/轻量/夜间自适应检查、新闻计划/补跑/Token/调用次数、金价、OpenAI 月费用、会员手动资料与显示开关、Wi-Fi、坚果云、配置恢复及固件构建/刷写入口。

## 缺失与显式值

升级时，缺失字段才补入新版默认值；用户明确写入的 `false`、`0`、`null`、空字符串或空数组保留原意，不会因为“看起来为空”而被默认值覆盖。配置加载不会自动改写旧文件；迁移必须先预览再确认。

## 何时生效

- 立即或下一次读取：日期显示、会员资料、页面显示开关、OpenAI 费用轮询、新闻生成参数。
- 下一期：新闻 Token 与每期调用上限；同一期重试继续使用创建时快照。
- 下一次设备获取策略：活动时段、自适应检查、补跑检查和页面切换。
- 必须重新构建并刷写：Wi-Fi、坚果云编译凭据、联网总预算以及固定硬件参数。

没有 Admin API Key 时，OpenAI 月费用显示“未配置/--”，不得伪造为 0。缓存陈旧、网络不通或云端不可用时显示对应状态。

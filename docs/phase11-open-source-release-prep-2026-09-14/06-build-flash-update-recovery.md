# 构建、刷写、更新与恢复

## 固件依赖

首个支持环境固定为 `epd_426_ssd1677_s3_n32r16`。PlatformIO Espressif32 固定为 7.1.0；该环境依赖固定为 GxEPD2 1.6.9、Adafruit GFX 1.12.6、WebSockets 2.7.3、ArduinoJson 7.4.3、NimBLE-Arduino 2.5.1。本次版本来自现有本机缓存，尚未在全新电脑重新下载验证。

```bash
cd shared/firmware
platformio run -e epd_426_ssd1677_s3_n32r16
```

没有运行 MiSans 导入时，缺少生成字库应被视为构建前置条件未满足，不能从候选包偷偷带入字体。

## 更新与新板

- 已有设备安全更新：只写应用相关分区，保留 NVS；仍需核对目标芯片、32 MB Flash、构建摘要和配置指纹。
- 全新空板：写入引导、分区与应用等完整产物；不能把已有设备更新流程当成空板初始化。
- 本阶段只构建和检查，不自动烧录。任何实际写入都应在识别 USB 设备后再次确认。

## 配置与管理员恢复

配置保存为草稿，确认应用后才成为有效配置。失败保留原有效配置和草稿。旧标签页、过期草稿或基准变化会拒绝覆盖。

管理员没有默认密码。忘记密码时，在后台所在电脑运行：

```bash
shared/backend/.venv/bin/python shared/tools/admin_recovery.py
```

工具隐藏输入、二次确认并要求确认短语；没有远程免登录重置接口。

## 常见问题

- 页面显示 `--`：对应数据未配置、未知或没有完整快照，不等于 0。
- 没有新闻 Key：应显示本地每日寄语；如果仍保留旧新闻，检查当前一期与缓存新鲜度。
- 金价显示成汇率：先检查结构化字段映射和数据新鲜度，不要用显示值反推接口成功。
- Wi-Fi 改名后无法连接：新名称/密码必须重新构建并刷写或从设备配网入口写入 NVS。
- 屏幕没有更新：区分后台生成成功、云端发布成功、设备联网、设备拉取和墨水屏刷新五个状态。

# 验证与当前门禁

日期：2026-09-14

## 必须通过

- 发行输入与候选运行文件都只有四条已确认文本，ID 和正文逐字一致，许可均为 `GPL-3.0-only`。
- 生产文件 SHA-256 在构建前后不变；候选不包含旧 12 条运行语料或 `CC0-1.0` 运行标签。
- 四条文本均通过设备字符清单和 800×480 正文最多四行、每行不超 744 px 的校验。
- 同一日期和期次重复选择结果一致；进程重启后结果一致；最近四条均已用过时有界回退，不返回空值、不死循环。
- 无密钥、无启用来源时保持本地寄语，零 RSS、零远程寄语 API、零模型调用。
- 全量测试、实际 ZIP 全新解压测试、隐私/秘密/字体/路径扫描、许可一致性和两次确定性构建通过。

## 状态定义

上述检查全部通过且没有其他工程阻塞时，收据可写 `publication_ready=true`，含义仅为“工程候选可发布”。它不是法律认证、不提供非侵权保证，也不代表用户授权本任务上传或公开发布。生产部署时若主动开启远程来源，仍须逐源审查条款。

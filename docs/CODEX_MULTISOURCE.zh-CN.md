# 多源线索与精简预告

> 下文保留 test.17 已发布契约。test.18 已加入时间待定、持久系列、独立辅助重试及原文菜单，当前实现以 [可信预告 v2](CODEX_FORECAST_V2.zh-CN.md) 为准；历史 v1 契约只用于溯源，不代表旧固件支持 v2。

此功能仍为实验性，开源默认 `codex_announcements.enabled=false`。
`whenreset_enabled`、`nextreset_enabled` 也分别默认 false。
需要明确开启才尝试读取固定来源，不支持用户任意填入外部 URL。

## 证据与限制

FxEmbed 的固定公开 HTTPS 接口为原文确认来源，核对指定作者的稳定 ID、帖 ID、原始发布时间和本人回复链。
明确 Codex 重置语境、可靠未来时间均必要；套餐未说明可以显示，但详情注明“适用套餐未说明”，
不推定所有套餐适用。明确排除当前套餐则不上屏。相邻编号的本人重置系列可补足产品语境，
不能用普通 reset 玩笑、转帖或别人的引用作为原文确认。

whenreset.dev/codex 与 nextreset.ai/history/ 只做可降级的实验性 HTML 原帖链接发现。
尚未确认它们有稳定、公开、获支持的机器 API，不能把网页可浏览等同于稳定自动接口。
读取前检查 robots；未知/失败不读取正文，403 不绕过。只保存少量原帖链接与字段线索，
不执行脚本，不使用用户 Cookie、Key、付费 API 或模型。NextReset 历史案例并非实时 feed。

第三方发现的作者原帖必须回到 FxEmbed 核实作者、日期和本人上下文，才可能生成事件。
各来源同一原帖去重，不以多数票证明套餐或日期。网页预测、倒计时、平均间隔不生成承诺。
辅助时间线索与主源字段分别保存；诊断列出待人工比较的时间/时区，不静默覆盖原文。
明确 PST 固定 UTC-8，PDT 固定 UTC-7，PT 才使用洛杉矶季节时区；“明天”先以作者明确时区的发帖日期计算。

同一事件最新明确更正生效；明确撤回、完成、不可用证据持久保存，不因另一来源成功返回旧缓存复活。
来源失败不是“没有事件”，保留最近验证证据，但显示仍按本地截止撤下。
预告不代表账户到账，不修改实际额度、手动次数、有效期，不用任意额度上涨证明兑现。

## 请求预算

主源保持原独立额度分档、临近事件和夜间 00/06 规则，每次操作最多 4 个主源 GET。
辅助补查只附着于原已获准主源轮询，不增加夜间唤醒；每站独立最少 2 小时冷却，
每次最多 robots 和正文两个 GET，robots 成功缓存一天。平台 Crawl-delay / Retry-After、403 及失败退避优先。
按需发现和正常补查共用严格冷却，不因每篇帖子或主源加速就同时重查所有站。
辅助失败不会阻止主源已有可靠事件，且诊断公开每站实际能力、成功时间和失败原因。

## 显示

配额重置、机会发放、类型未明重置中只显示未来最近一次。
“预计”在 y225、“MM-DD HH:mm 前重置/前发放”在 y256，均右对齐进度条 x461；
明确精确时刻而非截止时刻省略“前”。类型未明显示“重置”，不猜成发放次数。
删除底部所有预告括号，保留真实次数/到期行。零次时底部仍按原 fallback 规则显示，
上方预告独立存在。预告临时占用可选额度区域，但不修改配置开关，撤下后恢复。

菜单仍只加一个星号；有有效计划但额度未知为 `Is -*`。详情注明套餐未说明及原文字面时区。
公开网页预览继续使用成功上传并 GET 校验的完整快照与同一文档时钟，不退回重拼缓存。
普通轮询时间变动不改变活动信号、新闻页视觉键或额外切页。

# 发布门禁与权利人最小确认

日期：2026-09-14

## 当前结论

技术发布候选继续标记为**禁止发布**。顶层 GPL-3.0-only 已确定，但以下事项不能由代码扫描代替权利人决定。

## 发布前必须关闭的门禁

| 门禁 | 当前状态 | 谁确认 | 关闭条件 |
|---|---|---|---|
| 后续新增内容的 GPL 授权权利 | 阻塞 | 项目发布者/各权利人 | 确认有权将非第三方的后续新增代码、文档和界面文本按 GPL-3.0-only 发布 |
| `daily_messages.json` 的 CC0 资格 | 阻塞 | 文案权利人 | 确认全部文本自有或已有足够权利作 CC0-1.0 声明；否则改许可或替换/删除 |
| TechCrunch 自动摘要 | 阻塞公开运营 | 项目运营者 | 获得允许改写/展示的许可，或默认关闭该来源 |
| The Verge 自动抓取/摘要 | 阻塞公开运营 | 项目运营者 | 获得许可，或默认关闭该来源 |
| 其他 RSS 的公开 AI 摘要 | 待确认 | 项目运营者 | 逐源确认条款，保留来源、原文链接和时间，并提供开关 |
| MiSans 分发 | 已由工程隔离 | 发布者复核 | ZIP 中持续不存在原始字体、生成头、字形缓存和预览 |
| 私密数据 | 已由工程扫描 | 发布者最终复核 | ZIP 扫描为 0，并人工抽查示例配置均为空/占位符 |

## 权利人可直接确认的最小声明

1. 我确认自己拥有或已获得足够权利，将本项目中不属于已标注第三方的后续新增代码、文档与界面文字按 GPL-3.0-only 发布。
2. 我确认 `shared/backend/data/daily_messages.json` 的全部文本可由我合法声明为 CC0-1.0；如不能确认，将在发布前替换、删除或采用正确许可。
3. 我选择在公开运行前关闭 TechCrunch 与 The Verge 的自动抓取/AI 摘要，除非另行取得书面许可。
4. 我理解外部 API、RSS、金价和 WebDAV 账号由部署者自行注册和配置，其条款、隐私告知、费用、内容准确性与密钥安全不由 GPL 许可证覆盖。

这些确认应保存在项目发布记录中。确认完成后再修改构建器中的 `publication_ready` 和 `PUBLICATION-BLOCKED.md`；当前不应绕过门禁。

# InkSight license scope

InkSight project-owned source code in this distribution is offered under
`GPL-3.0-only`; the complete license text is in `LICENSE`.

This statement applies only to material the InkSight distributor is entitled to
license. It does not replace or weaken third-party notices, copyright headers,
trademark rules, service terms, data-source terms, or asset licenses. Files and
dependencies identified in `THIRD_PARTY_NOTICES.md`, `LICENSES/`, and `SBOM.json`
remain under their stated terms. If a file carries a more specific notice, that
notice must be preserved.

The source archive intentionally does not contain MiSans font files, generated
font headers, firmware binaries, private configuration, databases, logs, caches,
or unverified image assets. Users obtain allowed external resources themselves
and are responsible for the corresponding terms.

The checked workspace has no Git metadata. File-level comparisons can show that
some files match named upstream revisions, but they cannot reconstruct the exact
fork point or prove ownership of later additions. For this candidate, the
publisher selected `GPL-3.0-only` for project material and approved four local
daily messages under that same scope. The release builder substitutes those four
messages for the separate 12-entry, CC0-labelled production corpus; the latter is
not distributed in the candidate.

`PUBLICATION-READY.md` records engineering gate status only. It is not legal
certification, a warranty of non-infringement, or authorization to upload or
publish the archive.
